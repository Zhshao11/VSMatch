# V2（DINO 辅助）分支的零训练旁路：诊断性实验

> **定位（先读这段）**：这是**敏感性诊断**，不是合格的模块消融。
> 它在冻结权重上把融合门控置零，测的是「这个已收敛的管线能不能直接被拆」，
> **不能**用来量化 V2 分支的边际贡献，也不构成「DINO 那一路有多重要」的证据。
> 数字只能作内部诊断，**不宜进论文消融主表**；若引用必须连同下面的边界一起给。
> 真正能回答「该不该保留 V2」的实验是 §4.1 的 retrain-under-removal。

> 2026-11-14 于 zzvr 完成。全部数字为 **GDROS 官方 `test.py` 口径**（逐分量
> `|Δx|,|Δy|` + 配对级聚合），OS 测试集 **424 对全量**，`iters=32`、
> `LSR NPOINT=200000`。口径定义见 [EVALUATION_PROTOCOL.md](EVALUATION_PROTOCOL.md)，
> 原始数据见 [`ablate_v2_off_result_official.json`](../research/results/OS_20261114/ablate_v2_off_result_official.json)。

## 1. 实验定义

**诊断问题**：`E075A-M4@80K` 的 4D feature pyramid 由两路前端各建一个相关体。
**不重训、直接把 V2 那一路的贡献置零**，这个已收敛的管线会退化到什么程度？
（注意这不等于「单路模型效果如何」，后者需要重新训练，见 §4.1。）

**做法**：零训练消融 —— 不新增训练、不改层维度、不反向传播，只把融合门控的值改掉，
在**同一进程 / 同一份权重 / 同一评测口径**下跑两路与单路。

| 位置 | 原始 | 消融后 |
|---|---|---|
| F3 相关体融合 `corr = (1-a)·Corr1 + a·Corr2` | `a = sigmoid(corr_gate_logit)`，训练后 `a ≈ 0.5` | `corr_gate_logit = -80` → `a = 0` → 只用 `Corr1`(V1) |
| F2 特征融合 `fs = (1-gs)·f1s + gs·proj(...)` | `gs = sigmoid(fuse_gate(cat([f1s,f2s])))` | `fuse_gate` 换成恒定 `-80` 输出 → `gs = 0` → `fs = f1s` |

M4 的 B 分支（F2/F3）与 C 分支（F2/F3/student）共 **5 个**
`E073FusionMatcher` 实例（`variants=['F2','F3','F2','F3','F3']`），全部一起切换。
实测 `orig_corr_gate_logit = [0.0, 0.00261, 0.0, 0.00261, 0.00701]`，即门控
几乎没学动、两路始终各占一半。

**可信度校验**：同一次运行先跑 GDROS 官方权重，再跑 M4 两路，最后跑 M4 单路；
脚本把 `gdros` 与 `both` 对照 2026-11-13 官方口径历史值逐项核验，
10 项全部 `PASS`（`SANITY PASS`），`gdros` / `both` 的 AEPE 分别复现
`1.4618` / `1.4738`。只有这一步通过，`v2off` 的结论才成立。
probe 首对 `max|Δpost| = 56.04`、`mean|Δpost| = 14.73`，确认消融确实改变了输出。

## 3. 逐对差值（不是均值假象）

`ΔEPE = EPE(v2off) − EPE(both)`，正数表示去掉 DINO 后变差：

| 统计 | 值 |
|---|---|
| mean Δ / median Δ | **+6.2719 / +6.0892** |
| 变好的配对 | **15 / 424（3.5%）** |
| `Δ > +1 / +2 / +5 px` | 391 / 369 / 261 对 |
| `Δ < −1 / −2 / −5 px` | 11 / 10 / 5 对 |

恶化最大的 10 对（0-based 索引，`both → v2off`）：
`55: 1.37→20.61`、`336: 0.74→19.75`、`194: 2.26→20.04`、
`281: 0.54→17.07`、`243: 0.69→16.95`、`418: 2.05→18.00`、
`237: 0.98→16.83`、`70: 11.52→27.04`、`135: 1.83→17.22`、
`68: 3.48→18.67`。

中位数与均值接近、96.5% 的配对变差，说明这是**整体退化**，不是少数灾难失败
拉高均值；而这与 `both` 自身已知的「约 10% 配对级灾难失败造成松阈值尾部」
是两件不同的事。

## 4. 结论与边界

**能成立的结论（只有两条）**：

1. **耦合度诊断**：冻结的 `E075A-M4@80K` 在推理时**无法直接旁路** V2 —— 下游
   B/C 学生、LSR 之后的 L4 区域门控都是在 `a≈0.5` 的混合相关体/特征分布上收敛的，
   把 `a` 改成 0 是**换输入分布**，不是「减掉一个模块」。
2. **门控行为**：`corr_gate_logit ∈ [0, 0.007]`、训练后 `a≈0.5` 且 5 个实例一致，
   说明标量门控**没有学会把权重压向某一路**。这是关于训练动态的结论，与
   「DINO 分支是否必要」无关。

**不能成立的推论**：

- ❌「V2 贡献了 6.27 px 的 AEPE」「去掉 DINO 模型就废了，所以它很关键」——
  大退化主要由下游 OOD 解释，无法把退化量归因到被移除的那一路。
- ❌「V1 那一路本身弱」——`v2off` 的 `AEPE 7.7457` 反而比 GDROS 官方权重
  `1.4618` 差 5.3 倍。若只是少了 DINO 信息，结果应落在接近 GDROS 的区间；
  这个反常差距本身就是**下游失配**的证据，而不是表示能力的证据。
- ❌「重训单路也这么差」——本次没有任何参数被重新优化。

**为什么会这样**：这是一个**不对称推断**。零训练旁路只有「几乎不掉点」时才
有较强的解释力（冻结模型都不敏感 ⇒ 该分支大概率冗余，可直接拆）；
「大幅掉点」几乎不携带信息，因为它同时混合了「少了一路信息」和
「下游见到没训练过的输入分布」两个原因，且无法分离。本次属于后者，
所以它只能回答「不能直接拆」，不能回答「值不值得留」。

### 4.1 要真正回答「V2 值不值得留」，需要什么

合格的模块消融必须控制训练预算、数据与下游适配，只让「有无 V2」这一个变量变化：

| 方案 | 做法 | 成本 | 能回答什么 |
|---|---|---|---|
| A. 适配性续训（最小可用） | 固定 `a=0`，冻结前端，只续训 B/C + L4 gate 2K–8K 步，再跑同一官方口径 | `0.741 s/step` ⇒ 25 min–1.6 h + 一次评测 | 下游重新适配后，单路能否接近两路；这是**便宜的近似下界** |
| B. 严格重训（可写进论文） | 单路重训 E073 → E074 B/C → M4 gate，同数据同预算 | 约 27 h 纯训练，实际 1.5–2 天 | V2 的边际贡献，唯一能支撑「该不该保留」的结论 |

方案 A 的历史窗口要注意：≲2000 步稳定，**4000 步会让 CMR@1 崩塌**
（`tail_finetune`），所以续训步数本身就是需要扫的超参，不能只跑一个值。
在 A 或 B 完成之前，本页数字**不得**作为模块贡献度引用。

### 4.2 其余边界

1. **V2 前向仍然执行**：DINO 描述子照常计算，只是其贡献被乘以 ≈0。
   本实验没有测算力/显存收益，只测精度。
2. 只覆盖 OS 测试集 424 对、单个 checkpoint（`M4_step80000.pt`）。
   评测侧 LSR 取固定连续切片、无随机采样，因此结果可确定性复现，但未评估
   不同 step / 不同数据集上的一致性。
3. 本次实验仍有工程价值：确认 5 个 `E073FusionMatcher` 全部被切换、
   输出确实改变、官方口径链路 `SANITY PASS`；并且它是决定「要不要投入 27 h
   做方案 B」的一个廉价筛选信号。
