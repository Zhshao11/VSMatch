# 适配性短训：两个单路配置的受控对比（方案 A）

> **定位**：这是 [`ABLATION_V2.md`](ABLATION_V2.md) §4.1 的方案 A —— 固定单路、
> 冻结前端、给下游一小段适配预算。它比零训练旁路前进了一大步，但**仍不是
> 同预算严格重训单路**（方案 B）。结论能回答「零训练旁路的数字能不能当贡献读」，
> 不能回答「删掉某一路重训到收敛会差多少」。

2026-11-15 在**剪枝后的 E075A-M4@80K** 上，对两个单路配置各做 2000 步短训，
两张 GPU 并行，训练后同进程按 **GDROS 官方 `test.py` 口径**（424 对、
`iters=32`、`LSR NPOINT=200000`）评测。

## 1. 受控变量

两个配置**只有「门控锁在哪一侧」不同**，其余全部相同：

| 项 | 值 |
|---|---|
| 初始化 | 同一份 `M4_step80000.pt`，`c_skip_teachers=True`（剪枝版） |
| 门控 | `v1only`: `corr_gate_logit=-80`(a=0)、`fuse_gate=-80`(gs=0)；`v2only`: 均 `+80`(a=1, gs=1)；训练中锁死不更新 |
| 训练数据 | 保护版本 M4 的 `data_view`（OS training split，2011 对），同一 `seed=901`、同样本顺序 |
| 预算 | `steps=2000`、`train_iters=12`、`lr=2e-5`、AdamW(wd=1e-5)、grad clip 1.0 |
| 损失 | `lseq + lgeo + 0.35·gate_bce + 0.20·tail_cvar + 0.12·bucket`（原 M4 主要项；0.03/0.05 的 entropy/balance 两个小项在**两侧都省略**） |
| 可训练参数 | **4,401,475**（两配置完全相同） |
| 冻结 | 所有 E072 前端 `b1`/`b2`（含冻结 DINO/E046 注入）、`corr_gate_logit`、`head_gate_logit`、常量 `fuse_gate` |

### 1.1 结构事实：B 分支的递推链拿不到梯度

`E074Model(B).teacher_preds` 整体包在 `with torch.no_grad():` 里，因此 B 的
f2/f3 两条递推链**无法被续训**；解冻它们只会浪费优化器状态。真正有梯度的只有：

| 组 | 参数量 |
|---|---|
| L4 区域门控 `PairFusion.gate` | 9,281 |
| B 分支 `GateNet` | 7,265 |
| B 分支 `scalar` | 1 |
| C 分支 `student.context` | 1,066,848 |
| C 分支 `student.update` | 3,120,960 |
| C 分支 `student.fuse_proj` | 197,120 |

即 **C.student 是唯一可训练的递推链**。这意味着本次短训的「下游适配」能力
有明确上限，解读残余差距时必须计入这一点。

实测稳态约 **0.605–0.69 s/step**，训练 1263 s（v1only）/ 1382 s（v2only），
官方口径 424 对评测 350 s / 426 s。

## 3. 能成立的推论

1. **零训练旁路的大幅掉点主要是下游 OOD，不是「少了那一路信息」。**
   2000 步、只动 4.4M 下游参数，就把 AEPE 落差的 **95–96%** 拉回来，
   且两个配置短训后的 >10px 灾难失败都降到 **17 对**（`both` 是 12 对）。
   这把 11-14 的「不对称推断」从定性判断变成了定量证据：
   `7.7457` / `41.3298` 绝不能当作任一路的边际贡献。
2. **残余差距集中在细精度，不在尾部。** `v1only` 短训后 CMR@2/5
   （83.96 / 92.22）已贴近 `both`（84.91 / 94.10），>10px 失败 17 vs 12；
   差距主要落在 CMR@1（62.03 vs 72.41，−10.4 pp）。
   `v2only` 更极端：CMR@5 回到 87.26、尾部同样 17 对，但 CMR@1 只有 3.54。
3. **`v1only` 比 `v2only` 更容易适配**（1.7127 vs 3.3824）。与其结构一致：
   V2 特征本身是 V1 特征被 DINO 调制的结果、F2 在 `gs=1` 时输出
   `fuse_proj(cat([f1s,f2s]))`，下游在训练中从未单独见过这种输入；
   训练日志里 `v2only` 的 loss 到最后仍在 22–60 之间大幅波动，
   `v1only` 的训练批 flow5 早已接近 100%。
4. 训练批 `mat5≈100%` 而测试集 CMR@5 只有 92.22% / 87.26%，
   **训练集缺少 >5px 失败样本的覆盖缺口仍在**，与既有结论一致。

## 4. 不能成立的推论

- ❌ **不能把短训后的残余差距（+0.24 / +1.91 AEPE）当作某一路的边际贡献。**
  预算只有 2000 步（保护版本 80K 步）、只有 C.student 一条递推链可训练、
  门控被锁死在训练中从未见过的极端值、且 `v2only` 尚未稳定收敛。
  这是「**有限适配预算下的可恢复性**」，不是「同预算重训单路的效果」。
- ❌ 不能说「DINO 那一路不重要」或「V1 更重要」。`v2only` 更差至少部分来自
  其输入分布偏移更大（§3.3），与「信息量」不是同一个量。
- ❌ **不能用 `v1only` vs `v2only` 的差距去分配 V1/V2 的贡献 —— 这是用错了对照。**
  两个配置**都运行 `front_v1`**：`E072Matcher._features` 里 V2 只是
  `e046(raw1, raw2, fs, ft)` 把冻结 DINO 描述子 FiLM/residual 注入到 **V1 特征**上；
  F2 在 `gs=1` 时输出 `fuse_proj(cat([f1s, f2s]))`，仍显式含 `f1s`。
  所以 `Corr2` 是「V1 特征被 DINO 调制后」的相关体，不是独立的 DINO 相关体。
  V1 在两行里是**共同基底、不是自变量**，两行的差只包含「门控选
  `Corr1`/`f1s` 还是选 `Corr2`/`fuse_proj`」以及「下游适配到哪种输入分布」。
  要量化 V2 贡献，对照组必须只改变「有无 E046 注入」并同预算重训。
- ❌ 反过来也不能把 `both` 与单路的差直接读成 V2 增益：那个差里同样混着
  「少一路」与「下游 OOD」。目前只能说 **`both` 优于两个单路，方向指向两路互补**
  （AEPE 1.4738 < 1.7127 / 3.3824，CMR@1 72.41 > 62.03 / 3.54，
  且 F3 训练后 `a≈0.5`、优化并未把门控推向任一侧），不构成定量归因。
- ❌ 不能把本结果直接搬去解释 **M4 自身**的 >10px 尾部问题：这里评的是
  单路短训模型，不是保护版本 M4；要验证得在 M4 上做同样操作。
- ❌ 仍不宜进论文消融主表作为模块贡献数字；可以作为「零训练旁路无效」的
  方法学证据引用。

**要真正量化边际贡献**，仍需方案 B：同数据、同预算（80K 步）严格重训单路
E073 → E074 B/C → M4 gate，约 27 h；或至少把本方案的预算扩大到
与保护版本可比、并解冻更多下游参数。
