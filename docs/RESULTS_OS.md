### 1.5 V2 分支的诊断性零训练旁路（2026-11-14，官方口径 424 对，**非模块消融**）

在冻结权重上把 F3 的 `corr_gate_logit` 置 `-80`、F2 的 `fuse_gate` 换成恒定
零门控，旁路 V2 那一路。GDROS 官方权重与 M4 两路均通过 2026-11-13 历史值
`SANITY PASS`。**下表是敏感性诊断值，不能作为 V2 的边际贡献引用，也不宜进论文消融主表。**

| 配置 | AEPE↓ | CMR@1↑ | CMR@2↑ | CMR@5↑ | RMSE↓(官方栏位/方差) |
|---|---|---|---|---|---|
| GDROS 官方权重 | **1.4618** | 33.73 | 81.60 | **99.53** | **0.7463** |
| **M4 两路（保护版）** | 1.4738 | **72.41** | **84.91** | 94.10 | 8.3350 |
| M4 单路 V1（v2off） | 7.7457 | 0.94 | 4.25 | 24.76 | 16.0190 |

逐对 `ΔEPE = v2off − both`：mean `+6.2719`、median `+6.0892`，仅
`15/424 (3.5%)` 变好，`391/424` 恶化超过 1 px —— 是整体退化而非少数尾部拉高均值。

**边界**：冻结权重、零训练，下游 B/C 学生与 L4 门控在 `a≈0.5` 的融合分布上训练，
换纯 V1 属输入分布偏移。大幅退化混合了「少一路信息」与「下游 OOD」两个不可分离
的原因；`v2off 7.7457` 甚至比 GDROS `1.4618` 差 5.3 倍，本身就是下游失配的证据。
**唯一能成立的结论是「这个冻结管线不能直接拆」，不是「V2 重要」或「单路重训也这么差」。**
有效消融需重训单路，方案与成本见 [ABLATION_V2.md](ABLATION_V2.md) §4.1。

### 1.6 关于 `iters` 的口径提醒

§1.1 的 GDROS 与 M4 行都在 **`iters=32`** 下测得。零训练 GRU 迭代 sweep 显示
`iters=24` 时 M4 的 AEPE 为 `1.4449`（优于 32 的 `1.4738`）、`16` 为 `1.4611`，

## 2. 误差结构：尖峰 + 重尾

按逐像素口径（404 对）分桶，占比 %：

| 方法 | ≤1 | (1,2] | (2,5] | (5,10] | >10 |
|---|---|---|---|---|---|
| GDROS | 18.58 | 34.63 | 40.30 | 5.93 | **0.56** |
| **M4@80K** | **54.94** | 22.35 | 11.93 | 5.10 | **5.68** |

两个精确恒等式：`CMR@10` 差 5.12 pp == `>10` 桶差 5.68−0.56；
`CMR@5` 差 4.29 pp == `>5` 占比差。**M4 在松阈值上的全部落后，100% 由
>5 px 尾部解释**，与 (2,5] 区间无关。

**为什么「更准」反而 AEPE 更高**：M4 多数像素极准（≤1 px 是 baseline 的近 3 倍），
但约 6% 的灾难配对有 10–20 px 误差；AEPE 与 RMSE 对平方尾部极敏感
（向量 EPE 口径 RMSE 2.7031 → 5.1561），把少数大误差放大。

**三种「RMSE」不要混**（官方口径下）：

| 定义 | GDROS | M4@80K | 倍数 |
|---|---|---|---|
| 官方打印 / 论文表格的 `np.var(MAE_list)` | 0.7463 | 8.3350 | 11.2× |
| 论文公式 (15) 的 `sqrt(var)` | 0.8639 | 2.8870 | 3.34× |
| 逐分量误差的 `sqrt(mean(e²))` | 2.0333 | 3.8669 | 1.90× |

无论哪种 M4 都更差，配对级方差被放大得最狠 —— 因为它是**配对级 EPE 的方差**，
而 M4 的误差分布恰好是尖峰 + 重尾。对外报数必须写明用的是哪种定义。

**换惩罚方式结论反转**：截断式 `mean(min(e, τ))` 下 M4 三个阈值全面更低
（配对级 clip@1/2/5 = 0.7652 / 1.0754 / 1.5025，GDROS = 0.9841 / 1.6829 / 2.2462）。
即 M4 的全局劣势完全由少数超阈值的大误差配对驱动，而非整体精度退化。

## 3. Top-25 失败配对归因

排序指标为官方口径的配对级 EPE；按向量 EPE 排序的 Top-25 与之**完全重合（25/25）**。
诊断全量均值 `epe_post=1.4738`、`epe_gdros=1.4618`，与主评测逐位一致。

| 指标 | Top-25 | 其余 399 | 全部 424 |
|---|---|---|---|
| EPE（LSR 后） | **11.2768** | 0.8596 | 1.4738 |
| EPE（LSR 前） | 11.2481 | 0.9918 | 1.5965 |
| oracle(B,C) | **9.1815** | 0.6612 | 1.1636 |
| **GDROS（同对）** | **1.2595** | 1.4745 | 1.4618 |
| ΔLSR（后−前） | +0.0287 | −0.1322 | −0.1227 |
| 门控相对 oracle 差距 | 2.0953 | 0.1984 | 0.3102 |
| GT 尺度 | **1.0880** | 0.9594 | 0.9670 |
| **平移误差 (px)** | **16.6448** | 1.1802 | 2.0920 |
| **平移增益 α** | **0.8022** | 0.9998 | 0.9881 |

按 GT 尺度分档（全量）：`<0.85` 71 对 / 0、0.85–0.95 121 对 / 1、
0.95–1.05 109 对 / 1、**1.05–1.15 共 123 对 / 23 对 EPE>5 px**。

判断（排除法）：

1. **LSR 几何重建 —— 排除**：23/25 对 `|ΔLSR| < 0.5`，拟合出的尺度/旋转几乎正确
   （`ds=−0.017`、`dθ=−0.225°`），错的是平移；且 IRLS / trimmed-LS 对灾难配对
   几乎无效（13.31 → 13.17）。
2. **区域门控 —— 次要**：灾难对上 `gate_mean` 0.6576 vs 正常对 0.6515，行为几乎相同；
   逐像素 oracle 仍 9.1815（20/25 对 >5 px）。确有局部选错支（`gate_gap>1` 占 15/25，
   典型 `000241`：B=4.400、C=19.277、gate=0.653 偏 C），但属二阶收益。
3. **跨模态特征匹配 —— 主因**：LSR 前就错（25/25 对 >5 px）；B/C 两支同时失效；
   GDROS 在同一 25 对上平均仅 1.2595（22/25 对 <2 px）；23/25 落在 1.10 档；
   机制是平移估计向内收缩（`α≈0.80`，最差 `000116` α=0.21、`000280` α=−0.31 方向反了），
   迭代在第 2 步后停在伪不动点。

> 不是所有 Top-25 都是收缩：`000163`（α=1.92）、`000070`（α=1.13）是平移过冲，
> 说明 1.10 档是主病灶但不是唯一病址。

## 4. 门控的实际行为

- M4 ≈ `0.5·(B+C)`：学到的门控相对盲平均只多 2.02 pp@1、0.91 pp@2，@5 几乎持平。
- 门控是**软融合**（sigmoid 连续），不是 argmax 硬路由；其误差天然被两支包住。
- **未校准**：门控最自信（g→0/1）的区间恰恰是 oracle 误差最高的像素（U 形），
  置信度与难度正相关，无法为尾部提供保护。

## 5. 结论与报数建议

1. **紧阈值是明确优势**：官方口径 CMR@1 72.41%，比论文 GDROS 高一倍以上；
   三档 `AEPE@τ` 低 36–47%。
2. **不能宣称全面超越**：CMR@5 落后 5.42 pp，官方栏位 RMSE 差 11.2 倍。
3. **短板机理清楚**：约 6% 的 1.10 档灾难配对（平移估计失效）造成尖峰重尾，
   发生在 E072/E073 跨模态稠密对应阶段，B/C 共同继承，门控与 LSR 都无法补救。
4. 对外报数时：明确标注误差度量（逐分量 vs 向量 EPE）、聚合单位（配对 vs 像素）、
   `RMSE` 的真实定义、`AEPE@τ` 是 inlier-mean 还是截断式；并同时保留 CMR@5
   与灾难配对占比，如实标注短板。
