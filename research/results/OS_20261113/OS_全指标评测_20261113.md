## 1. 口径定义（本次最容易混淆的地方）

GDROS 官方 `test.py` 的 `Registration_index_calculation(epe_list, T)` 中，`epe_list` 是**每对图像的平均 EPE**（`MAE_list`），不是逐像素误差：

- `CMR@T = 100 × |{pair_mean_epe < T}| / 总对数`
- `MAE@T（本文记作 AEPE@τ）= 通过阈值的那些配对的 pair_mean_epe 均值`
- **`RMSE = np.var(...)`**：官方代码把**方差**打印成 "RMSE"，是误命名。本文同时给出真 `RMSE = sqrt(mean(e²))` 与 `var（官方 RMSE 栏位）`。

历史项目里 `eval_os_unified.py` / E075A `eval_model` 用的是**逐像素**口径（`CMR@k = 有效像素中 e < k 的占比`）。两套口径数值差异很大，必须分开报，因此本次**两套都跑**。

本文的 `AEPE@τ` 采用官方语义：**阈值内样本的平均误差**。另一种常见写法是「截断式」`mean(min(e, τ))`（把失败样本按 τ 计入惩罚），见 §4。

## 4. 补充：截断式 AEPE@τ（`mean(min(e, τ))`）

inlier-mean 口径只看成功样本，会掩盖失败；截断式把失败样本按 τ 计入，同时反映精度与召回。该值可由同批统计量直接推导，无需重跑。

## 5. 结论要点

1. **紧阈值 M4 全面占优**：配对级 CMR@1 +43.16 pp（9.43→52.59）、CMR@2 +27.60 pp（52.12→79.72）；三个阈值的 `AEPE@τ` 与 `RMSE@τ` 也全部更低（如 AEPE@5 1.0665 vs 2.0810）。逐像素口径同向。
2. **松阈值 GDROS 占优**：CMR@5 94.34 vs 88.92（−5.42 pp），CMR@10/16 亦然。与既有「1.10 尺度档灾难配对」结论一致。
3. **全局 AEPE / RMSE 是 M4 的短板**：AEPE 仅 +0.045（2.3216→2.3669），但 **RMSE 几乎翻倍**（配对级 2.7031→5.1561，逐像素 2.8755→5.4686），var（官方 RMSE 栏位）从 1.92 涨到 20.98。RMSE 对平方尾部极敏感，把少数大误差配对放大了——这正是「尖峰 + 重尾」分布的直接量化证据，不是评测误差。
4. **换惩罚方式结论反转**：截断式 AEPE@τ 下 M4 三个阈值全面更低。即 M4 的全局劣势完全由少数超出阈值的大误差配对驱动，而非整体精度退化。对外报数时必须写明用哪种 AEPE@τ 定义，否则会得出相反结论。
