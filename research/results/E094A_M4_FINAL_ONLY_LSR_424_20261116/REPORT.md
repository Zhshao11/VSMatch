# M4：129 次 LSR 裁剪为 5 次的全量验证

2026-11-16 完成；实验于 2026-11-15 启动。固定 OS E075A-M4 step80K 权重，没有训练或微调。

**424 对全部通过：同环境重跑的129次版与5次版，原始位移和post-LSR位移逐元素完全相同，最大差值均为0。平均耗时下降 45.04%，加速 1.819 倍。**

## 修改范围

保持32轮GRU、特征与相关金字塔、所有网络权重、最终轮门控、20万点官方LSR和末端拟合不变。
只对最终轮计算B门控及M4门控，省略不参与最终结果的中间轮门控及其LSR特征。
调用次数从 `2×32 + 2×32 + 1 = 129` 变成 `2 + 2 + 1 = 5`，逐对实际计数均符合预期。

实现是独立函数 `research/remote_stage/os/m4_final_only_lsr.py:forward_final_only`，返回最终原始位移，调用方再执行一次末端LSR。
原模型文件和权重没有修改。该入口仅用于eval，不能替换原有训练流程，也不返回中间轮融合结果。

本次使用的远端模型默认 `c_skip_teachers=True`，两版均跳过C的两个teacher；这不是本次新增的优化。
先前10对测试的文字曾误称保留teacher，已根据相同源码哈希更正；其原始计时和LSR计数有效。
较早本地架构快照仍含teacher执行路径，复现耗时时应确认具体源版本和开关。
