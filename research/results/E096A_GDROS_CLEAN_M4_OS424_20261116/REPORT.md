# GDROS 与精简 M4：官方 OS424 全量配对评测（E096A，2026-11-16）

本轮已重新推理两种方法的全部 424 对，不复用历史预测作为主表。M4 的 CMR@1/2 更高；GDROS 在整体平均误差、5 px 成功率、误差尾部和推理耗时方面更好。精简 M4 本轮平均耗时为官方 GDROS 的 **2.580 倍**。

M4 的 CMR@1/2 相比 GDROS 分别提高 38.6792 和 3.3019 个百分点，CMR@5 降低 5.4245 个百分点。按逐对分量均值比较，M4 在 331 对更低、93 对更高、0 对相同；这不代表其所有误差分布指标都更优。5 px 失败集合见 `PAIRED_SUMMARY.json`。

精简未改变 M4 的精度取舍：高精度成功率突出，少数大误差仍拉高均值。它也尚未将 M4 的有效推理计算降到 GDROS 水平。M4 保留三个各 32 轮的匹配器、5 个相关金字塔、冻结 DINO 和多级融合；GDROS 是一个 32 轮匹配器、1 个相关金字塔、无 DINO。注册参数不能直接当作有效可训练参数量或 FLOPs。

## 计时条件与比较范围

- zzvr 同一张 **NVIDIA GeForce RTX 5090，物理 GPU3**，共享 GPU；batch=1、512×512、FP32，两项 TF32 和 cuDNN benchmark 均关闭，CPU 数值库单线程。
- 每种方法在 0/211/423 三对上预热；随后每对均跑两种方法，并交替先后顺序，共 848 条计时记录。
- 同步 GPU 的墙钟计时包含网络前向、内部处理和最终官方 LSR；不含模型加载、图像读取、H2D、输出验证、保存和 GT 评分。
- GDROS 为原官方代码，含其原有中间输出计算；本轮未给 GDROS 实施 M4 的推理精简。M4 使用 E095A 已验证实现，全部迭代与有效分支保留。

本轮共享 GPU3 的 M4 平均值为 571.037 ms。上一轮 E095A 的 340.450 ms 来自共享 GPU6 及另一负载时段；本轮输出与其 424/424 逐元素一致，比较速度应采用本轮配对值。共享 GPU 结果有负载波动限制，不作为独占部署标准延迟。

## 精度与完整性验证

输入覆盖官方 OS 全部 424 对，包含困难样例，整图评测、无 valid mask、无子集筛选。公共分量误差为 `mean_pixels((abs(dx_error)+abs(dy_error))/2)`；CMR@t 是每对均值严格小于 t 的比例。向量 EPE 为 `mean_pixels(sqrt(dx_error²+dy_error²))`，单独报告。

所有 848 份预测保存后才读 GT 评分。两种方法严格加载已校验权重：

- GDROS：`80fd768e2d5f2f3887ff8af62b165e43e073e6cec187544c542b6d4b591ba683`。
- M4：`55d6e6cd7e849c5c25723004ef6b7a7c79b8cd55e2665951257cafb07b86d81b`。

当前 M4 与 E095A 归档的最大绝对差为 0.0，逐元素相同 424/424 对。运行前后源文件哈希一致；本地评测入口和精简模型源文件与运行快照一致。

已独立复算全部计时、均值/标准差/阈值统计，且重新计算全部 848 个 NPY 文件 SHA256，验证结果 PASS（`VERIFICATION.json`）。

GDROS 本轮分量均值与历史 E092A 的差为 +0.000175244 px，所有已报告 CMR 阈值比例一致。当前显式固定两项 TF32 设置，历史缓存运行设置不完全相同；本轮没有单独隔离验证这点均值差异的原因。主表使用本轮完整重跑值，历史记录保留。
