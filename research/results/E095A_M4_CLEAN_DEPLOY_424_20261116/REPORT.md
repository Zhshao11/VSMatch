同轮配对平均耗时减少 **45.24%**，提速 **1.826 倍**；注册参数总数减少 **79.43%**。参数统计包含冻结、重复和闲置权重，不等同于有效可训练参数量，也不代表 FLOPs 降低同等比例。

计时来自 zzvr 的共享 GPU6，batch=1、FP32、512×512、每个匹配器 32 轮，两个路径逐对交替先后顺序并同步 GPU。耗时包括网络前向和最终官方 LSR，不含加载、解码、H2D、保存及指标计算。它是本轮共享 GPU 的配对结果，不是独占 GPU 标准延迟；不能与此前其他 GPU 上的 129 次 LSR 耗时直接拼接计算总加速比。多项优化共同生效，本轮不归因单项提速。

## 删除或共享了哪些内容

| 内容 | 原路径 | 精简路径 | 判断依据 |
|---|---|---|---|
| 中间 mask head 与 8 倍上采样 | 每对各 96 次 | 各 3 次 | 前 31 轮高分辨率输出不反馈给 GRU；最后一轮保留 |
| 嵌套 V1/V2 上下文 CNN | 6 次 | 0 次 | 实际 FeatureEncoder.forward 不读取 context 参数；驱动 GRU 的 3 个主上下文编码器保留 |
| 冻结 DINO | 3 份活跃主干、6 次前向 | 1 份主干、2 次前向 | 三者状态 SHA256、类型、结构和网格相同，且冻结、eval；每幅图只计算一次 |
| 冻结光学/SAR 描述子适配器与插值 | 3 套 | 1 套 | 状态、结构、变体相同；缓存只在当前图像对内部生效 |
| 局部相关性查询偏移网格 | 每轮每层构造、传输 | 一个 buffer | 保留相同 ij 网格和采样算式 |
| F3 特征混合副输出、诊断标量传回 CPU | 计算后丢弃 | 不计算 | 最终推理只消费流预测 |
| C 教师、嵌套旧 update、unused cost perceiver、训练专用头、F3 未用融合层及标量 | 注册在模型中 | 精简模型不注册 | 不在最终推理依赖链中；其中 C 教师原对照已跳过执行，不能重复计入提速贡献 |

三个活跃匹配器的 CNN、主上下文编码器、GRU/update、FiLM 投影的对应整组权重不同，保留各自实现与参数。冻结适配器共享以完整状态与结构一致为条件，未来训练成不同权重会自动分组。

**未删：** B/F2、B/F3、C/student 三个匹配器；每个 32 轮，共 96 次 GRU/位移更新；5 个四层相关金字塔；有效 CNN/Transformer、FiLM 和融合门控；4 次内部 LSR 与 1 次最终 LSR。不能用“已经执行”证明这些分支都提高精度；有效性仍需独立消融。本次只清理已确认的依赖冗余。

## 等价性和指标复核

- 424/424 原始预测逐元素相同；424/424 LSR 后预测逐元素相同。
- 精简模型 540 个带参数叶子模块全部执行，未发现注册但未调用的参数叶子模块；mask 两个参数层在每个匹配器均只调用 1 次。
- 两个路径实际计数均为每对 5 次 LSR；未缩短 GRU 迭代。
- 当轮对照与 E094A 的 424 个归档 final5 输出也逐元素相同；E094A 已验证 final5 与 original129 等价。本次结果没有历史 E092 缓存与固定 TF32 设置不同导致的混淆。
- 全部预测先保存，再读取 GT 统计分量误差与向量 EPE；匹配和门控未读取 GT。
- 已独立复算 848 条计时、424 条逐对指标及所有阈值统计，并在 zzvr 重新计算全部 848 个预测文件哈希；结果通过。运行前后源文件哈希一致，本地源文件与运行快照一致。

公共口径每对误差为 `mean_pixels((abs(dx_pred-dx_gt)+abs(dy_pred-dy_gt))/2)`；CMR@t 为该误差严格小于 t 的图像对比例。向量 EPE 为 `mean_pixels(sqrt(dx_error²+dy_error²))`，应与分量指标分开比较。

输出等价意味着本次不会改善原来的 25 对尾部困难样例；本次收益是推理效率与模型存储。
