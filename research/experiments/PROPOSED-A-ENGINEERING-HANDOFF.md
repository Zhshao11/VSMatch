## Frozen Evidence Export

This stage requires separate user approval for GPU inference. No optimizer, backward, state update, augmentation, training, or test-set selection is permitted.

Primary common architecture:

- OS: released GDROS OS checkpoint, SHA in the OS manifest.
- WHU: released GDROS WHU checkpoint, SHA in the WHU manifest.
- Both use the same GDROS architecture and forward graph with independently trained dataset weights.
- Samples are deterministic 32-pair subsets from training data. They overlap checkpoint training and therefore support mechanism diagnosis only, not generalization claims.

Prepare views:

```bash
python .codex_tmp/proposed_a_prepare_evidence_view.py --manifest proposed_a_d1_os_evidence_manifest.json
python .codex_tmp/proposed_a_prepare_evidence_view.py --manifest proposed_a_d1_whu_evidence_manifest.json
```

Export bundles:

```bash
python .codex_tmp/proposed_a_evidence_bundle.py export --provider proposed_a_gdros_frozen_provider:records --manifest proposed_a_d1_os_evidence_manifest.json --output <root>/evidence/os
python .codex_tmp/proposed_a_evidence_bundle.py export --provider proposed_a_gdros_frozen_provider:records --manifest proposed_a_d1_whu_evidence_manifest.json --output <root>/evidence/whu
```

These commands are prepared but not GPU-validated. After approval, first run a one-pair inference smoke, verify strict checkpoint load and tensor shapes, then export at most 32 pairs per dataset.

## Evidence Schema

Each bundle contains `manifest.json`, `export_report.json`, `pairs/<pair>.npz`, and `labels/<pair>.npz`.

No-GT arrays:

- `source_features`, `target_features`: `[C,Hf,Wf]`;
- `coarse_flow`: `[2,H,W]`, original-pixel displacement;
- `source_xy`: `[N,2]`, feature-grid xy;
- `target_topk_xy`: `[N,K,2]`, feature-grid xy;
- `target_topk_score`: `[N,K]`;
- `inference_domain_mask`, `visibility_mask`: `[H,W]`.

Evaluation-only sidecar:

- `ground_truth_flow`: `[2,H,W]`;
- `evaluation_mask`: `[H,W]`.

The model runs before labels are materialized. D1 reads labels only after the no-GT evidence bundle is complete.

## D1 Matrix

Run separately for OS and WHU:

```bash
python .codex_tmp/proposed_a_d1_compare.py --bundle <root>/evidence/<dataset> --modes 3 --output <root>/d1_<dataset>.json
```

Required decomposition:

1. `capacity_best_translation` versus `capacity_best_affine`, GT-assisted and explicitly diagnostic.
2. `translation_pool` versus `affine_pool`, generated without GT from identical edges and matched candidate budgets.
3. On each fixed pool: `self`, `robust`, `heldout`, and offline `oracle` selection.
4. Report distinct-mode count, candidate count, CMR@1/2/5, AEPE, P90/P95, and >=5px failures.

Hard top-k, mutual filtering, clustering, and candidate generation are non-differentiable. Fixed-hypothesis evidence scoring is differentiable. Do not describe the whole path as end-to-end differentiable.

## Promote and Stop Rules

- If best affine capacity does not improve over best translation capacity, stop A's affine family.
- If affine pool oracle does not improve over translation pool oracle at matched budget, report `POOL_NO_GAIN` and do not train a selector.
- If affine pool oracle improves but held-out selection does not improve over robust/self scoring, report `HELDOUT_SCORE_NO_GAIN`.
- If held-out selection and pool reachability both improve, return evidence for a separate trainable-probe decision.
- Ambiguous 32-pair evidence may justify a separately approved 64-pair inference export, never an automatic 120K run.
