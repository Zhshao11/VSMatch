# E-028A：Dual-Adapter DINO Transfer with Modality-Invariant Supervision

方法版本：`M001 v3.2 prototype`

状态：`USER_APPROVED / READY_FOR_ENGINEERING`

## 1. 目标

E-028A 在 E-027A 正结果上做受控增强：E-027A 只训练 SAR adapter，把 SAR 对齐到 frozen optical DINO 空间；
E-028A 进一步给 optical 也加轻量 adapter/projection，并加入模态不变辅助监督，使 optical/SAR descriptor
更像同一种结构特征，而不是各自保留强模态偏差。

核心问题：

> 在同一个 E-025A fair matcher/NMS/affine evaluator 下，dual-adapter + modality-invariant losses 是否能
> 超过 E-027A 的强迁移特征？

本实验只证明 feature frontend gain；不宣称完整 sparse affine recurrent matcher 成功。

## 2. 已知对照

E-025A primary fair matcher：`topK256_nms2_quota4_mutual0`。

对照指标：

- `E027A_FROZEN_DINO_OPTICAL__SAR_ADAPTER`：AEPE `26.246`，recall@2 `0.569`，correct@2 `0.438`；
- `GDROS_FEATURE_FAIR`：AEPE `96.430`，recall@2 `0.729`，correct@2 `0.762`；
- `DINO_FOUNDATION_FAIR`：AEPE `79.246`，recall@2 `0.198`，correct@2 `0.163`；
- 完整 GDROS system 只能作为 secondary reference，不参与 primary feature baseline。

## 3. 数据与边界

- train/dev split：train `1607`，dev `404`。
- 原始 optical/SAR 固定 `512x512`。
- `truth_flow` 只用于 train loss、label 和 metrics。
- `datum` 仅做 archive 完整性/SHA，不作为标签。
- OS424/confirm 禁止参与。
- GDROS baseline、原始 DINOv2 checkpoint、历史 feature/cache/run 目录只读。
- 可训练 optical adapter/LoRA 只能存在于 E-028A checkpoint 副本，禁止修改原始 DINO checkpoint。

## 4. 模型路线

### Parity track：`E027A_FROZEN_DINO_OPTICAL__SAR_ADAPTER_PARITY`

复核 E-027A primary track，确认 E-025A matcher 与特征物化一致。可读取 E-027A 产物或等价重放，不要求重训。

### Primary track：`DUAL_ADAPTER_MODALITY_INVARIANT`

```text
optical 512x512
  -> frozen DINOv2 teacher/reference
  -> trainable optical residual adapter/projection
  -> optical descriptor in shared invariant space

SAR 512x512
  -> log/structure/speckle-robust SAR stem
  -> trainable SAR adapter/projection
  -> SAR descriptor in shared invariant space

shared descriptors
  -> E-025A primary fair matcher
  -> same affine evaluator
```

绑定：

- optical adapter 初始化为接近 identity/residual，避免破坏 DINO prior；
- optical teacher consistency 必须约束 adapted optical；
- SAR adapter 继承 E-027A 思路；
- primary 不能是 SAR-only、scratch-only 或 full optical DINO finetune。

## 5. Loss

必须包含：

- GT paired-token contrastive / sampled-softmax；
- optical teacher consistency；
- modality-invariant positive alignment；
- variance/covariance regularization，避免 descriptor collapse；
- domain-adversarial 或 modality-confusion loss；
- local-neighborhood structure consistency；
- cycle 或 mutual consistency；
- soft affine/grid loss；
- SAR augmentation consistency。

如果 domain-adversarial 训练不稳定，可作为 ablation 关闭，但 primary report 必须说明。

## 6. 评价

正式 dev 比较：

```text
-> same affine evaluator
-> compare with E-027A, GDROS_FEATURE_FAIR, DINO_FOUNDATION_FAIR
```

必须报告：

- endpoint recall@1/2/5；
- GT endpoint rank / topK recall；
- selected count；
- selected correct@2 mean/P50；
- fair affine AEPE；
- CMR@2 / CMR@5；
- PLR；
- target collision；
- region/quadrant coverage；
- train/dev gap；
- optical teacher drift；
- modality classifier accuracy/AUC if used；
- resource p50/p95/max、peak memory、frozen/trainable parameter counts。

## 7. Gate

### P0：implementation and isolation

必须 PASS：

- E-027A parity baseline present；
- DINOv2 pretrained weights loaded and original checkpoint readonly；
- optical adapter/projection exists, is called, and is trainable；
- SAR adapter/projection exists, is called, and is trainable；
- primary is dual-adapter, not SAR-only or scratch-only；
- copied checkpoint / teacher / initialization SHA recorded；
- no baseline writes；
- no OS424/confirm/datum；
- train/dev split isolation；
- feature materialized before truth_flow join；
- primary matcher config 与 E-025A 一致；
- no dev matcher/threshold selection。

P0 fail：`DUAL_ADAPTER_IMPLEMENTATION_BLOCKED`。

### G0：training sanity

必须 PASS：

- train loss finite 且主要 loss 非零；
- paired-token、teacher-consistency、modality-invariant losses active；
- gradients 到达 optical adapter 与 SAR adapter/projection；
- declared frozen DINO modules 保持 frozen；
- optical teacher drift bounded；
- strict checkpoint load；
- train no-GT hard matcher inference finite；
- train feature utility 超过 E-027A parity 或有明确 recall/correct gain；
- reviewer 对 dual-adapter/隔离链路 approve。

G0 fail：`DUAL_ADAPTER_TRAINING_BLOCKED`。

### G1：dev feature comparison

判读：

- `NO_DUAL_ADAPTER_GAIN`：dual-adapter 未超过 E-027A 的 AEPE/recall/correct 任一核心组合；
- `DUAL_ADAPTER_GAIN_FOUND`：相对 E-027A AEPE 改善 `>=10%` 且 recall/correct 不下降，或 recall/correct
  改善 `>=15%` 且 AEPE 不差于 E-027A 超过 `5%`；
- `GDROS_RECALL_BRIDGE_FOUND`：recall@2 或 correct@2 达到 `GDROS_FEATURE_FAIR` 的 `>=75%`，且 AEPE 仍显著优于 GDROS；
- `MODALITY_INVARIANT_STRONG_GAIN`：AEPE 改善 `>=20%`，且 recall/correct 同时优于 E-027A；
- `READY_FOR_SPARSE_FEEDBACK_FRONTEND`：feature 足够进入下一版 sparse feedback/coarse-to-fine。
