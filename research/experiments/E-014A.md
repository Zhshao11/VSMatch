# E-014A：Cross-modal Signal Ranking Diagnostic

## 目的

E-014A 回答：

> 在 E-011A top128 candidate 上，哪些 optical-SAR appearance / structure / descriptor 信号对
> endpoint correctness 有真实排序能力？

本实验是只读诊断，不训练新方法，不接几何反馈，不启动 sparse affine feedback。

## 输入

- E-011A top128 candidates：只读。
- official training archive raw `512x512` optical/SAR/truth_flow：truth_flow 仅用于 label join 和指标。
- E-013A pre-feedback endpoint score 与 final score：只读 reference track。
- 禁止：datum、OS424、confirm、测试集 GT。

## 信号列表

至少实现以下 signal families：

1. `raw_patch`
   - mean/std normalized NCC；
   - cosine；
   - L1/L2 negative distance。
2. `normalized_patch`
   - optical robust z-score；
   - SAR `log1p` + robust z-score；
   - CLAHE/contrast normalized patch，若库可用。
3. `gradient`
   - Sobel/Scharr magnitude NCC；
   - orientation histogram cosine；
   - multi-scale gradient descriptor。
4. `phase_congruency_rift`
   - phase congruency magnitude；
   - orientation/MIM-like code；
   - HOPC-style histogram。
5. `census_rank_self_similarity`
   - rank transform；
   - census/Hamming；
   - local self-similarity descriptor。
6. `structure_tensor`
   - eigenvalue/cornerness similarity；
   - edge orientation consistency。
7. `reference`
   - E-011A raw patch descriptor score；
   - E-013A pre-feedback endpoint score；
   - E-013A final score；
   - random score control。

若某 signal family 无法实现，必须写入 disabled stub，说明原因；不得静默缺失。

## P0：实现与协议 sanity

P0 必须全部 PASS，否则状态 `COMPLETED / IMPLEMENTATION_BLOCKED`，不得解释负面排序结果。

### 协议

- E-011A top128 parity PASS。
- 所有 signal scores 在 label join 前物化，记录 score file SHA 和 label join 时间顺序。
- source->target 方向固定为 optical source -> SAR target。
- stride-8 token xy 到 pixel xy 的转换一致。
- patch center、radius、padding、边界、采样方式固定并记录。
- no OS424/confirm/datum。
- no training、no checkpoint write、no baseline overwrite。

### Synthetic / sanity tests

- same-image identity patch：raw/gradient/census/NCC 正样本分数高于随机负样本。
- known shift patch：正确 shift 分数高于错误 shift。
- gradient orientation toy：方向 histogram 能区分水平/垂直/斜边。
- phase congruency / RIFT-style toy：结构边缘响应非空、方向码可复现。
- structure tensor toy：corner/edge/flat 区域统计可区分。

### Negative controls

- shuffled target patches：AUROC 接近随机。
- swapped source-target coordinate direction：应显著变差或被测试捕获。
- random score：AUROC 约 `0.5`，AP 约 base rate。

### 审阅

必须两路独立定向 reviewer：

- feature implementation reviewer；
- evaluator/protocol reviewer。

两者都必须 `APPROVE` 或 `APPROVE_WITH_RESULT_FAIL`。若有 blocking finding，停止。

## D1：candidate-level ranking

对每个 signal track 在 train/dev 报告：

- AUROC；
- AP；
- AUPRC；
- Brier/ECE 若适用；
- positive/negative score P1/P10/P50/P90/P99；
- positive rate。

## D2：source / pair / topK metrics

对每个 signal track 在 dev 报告：

- per-source positive rank：rank of first `<=2px` positive；
- global topK K=`8/16/32/64/128/256` 的 active/correct/precision/recall/coverage；
- per-region quota q=`1/2/4/8` 的 active/correct/precision/coverage；
- per-pair correct count P10/P50/P90。

## D3：组合诊断

只作诊断，不作为方法成功：

- z-score sum of selected handcrafted signals；
- train-only logistic regression / linear probe over signal scores；
- leave-one-signal-out ablation。

组合模型不能修改 E-013A status，不能作为 E-014B 自动启动依据。

## 判读

给唯一主判读，可附 secondary：

- `SIGNAL_FOUND`：至少一个非旧模型信号 dev AUROC `>=0.75`，AP `>=2x` E-013A pre-feedback endpoint AP，
  且 topK/quota correct 明显超过 pre-feedback track。
- `WEAK_SIGNAL_ONLY`：至少一个信号超过 random/final score，并接近或略强于 pre-feedback endpoint，但未达到 `SIGNAL_FOUND`。
- `NO_SIGNAL_FOUND`：所有信号接近 random 或不超过 E-013A pre-feedback endpoint。
- `IMPLEMENTATION_BLOCKED`：P0 或 reviewer 未通过。
