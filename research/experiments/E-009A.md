# E-009A：Learned Region-Conditioned Top64 Retriever

## 目的

E-009A 只回答一个问题：

> 在固定 E-008A source proposals 与 matched-region union 的条件下，训练一个新的跨模态局部
> retriever，能否超过 frozen cosine / region score 的 top64 预筛？

本实验不 rescue E-008A v1，不启动完整 sparse affine feedback。

## 方法

### 固定部分

- 复用 E-008A 的 dev/train split、source proposal 生成、4/8/16 region matching 和 matched-region union。
- S0/S1 trace 必须与 E-008A-STAGE-DIAG 一致。
- 不改变 region top-L、不扩大到 full image、不枚举全图 `4096x4096`。

### 新模块

训练 `LearnedRegionTopKRetriever`：

- 输入：原始 `512x512` optical/SAR，可加入固定结构通道（梯度、边缘、局部方差或 SAR log-intensity）。
  learned retriever 不得读取 GDROS frozen features；GDROS frozen features 只允许用于复现旧 S2 baseline。
- 输出：stride-8 `64x64` source/target descriptors 或等价 retrieval logits。
- 结构：轻量双模态 CNN/adapter，允许 modality-specific stem + shared projection；参数量建议 `<5M`。
- 检索：对每个 source proposal，只在其 S1 matched-region union 内打分，取 learned topR。
- R 曲线：`4/8/16/32/64/128`。

禁止把 frozen GDROS cosine / region score 作为 learned top64 ranker 或 learned retriever 输入。可以
记录它们作为 baseline/diagnostic outputs，但不得进入 learned score。

## 监督与损失

- 唯一标签来源：training split 的 raw `truth_flow`。
- 对每个 source proposal，在 S1 union 内用 raw endpoint 生成 token 标签：
  - hard positive：candidate target pixel 到 raw endpoint 距离 `<=2 px`；
  - soft target：允许以 nearest token 或 Gaussian distance target 训练，但必须在实验卡中绑定公式。
- 推荐 loss：
  - in-union sampled/listwise cross entropy 或 supervised contrastive loss；
  - in-bounds/dustbin 辅助 loss 用于处理 union 内无正样本 source；
  - 可选 topK recall surrogate，但不得使用 dev/test GT 调阈值。
- 必须检查 gradient 到达 trainable retriever，toy subset 能过拟合。

## Gate

### G0：实现与协议

- S0/S1 trace identity 与 E-008A-STAGE-DIAG 一致。
- frozen S2 baseline parity PASS。
- train/dev split、checkpoint、source SHA、data SHA 写入 `RUN_MANIFEST.json`。
- candidate outputs 在 label/eval join 前物化。
- 无 OS424/confirm/datum label、无 hidden N2、无 dense flow/GRU、无 fallback。
- 自动测试与 reviewer APPROVE。

### G1：top64 retriever 是否超过 frozen S2

learned top64 必须同时满足：

- mean 2px-correct proposals `>50.015`
- P10 `>26`
- P50 `>48`
- 2px candidate base rate `>0.05161%`
- nearest-distance P50/P90 不差于 frozen S2。

若 G1 FAIL，状态为 `COMPLETED / LEARNED_TOP64_FAIL`，停止。

### G2：是否具备候选生成资格

仅 G1 PASS 后判读。learned top64 作为 candidate generator 必须满足：

- mean 2px-correct proposals `>66.210`
- P10 `>33`
- P50 `>64`
- oracle affine AEPE `<=0.5 px`
- PairLocalReady/valid `>=99%`

若 G2 FAIL，状态为 `COMPLETED / TOP64_IMPROVED_BUT_NOT_QUALIFIED`，停止。

### G3：compact topR 诊断

报告 topR=`4/8/16/32/64/128` 的 correct proposals、base rate、nearest distance 和 oracle affine。
G3 不自动触发后续实验。
