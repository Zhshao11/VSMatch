# E-020B：Train-Full Candidate Verifier Learnability

## 目的

E-020B 回答：

> 当 4-pair overfit 不再作为硬停止，并将监督改为 source 内竞争、contrastive grouping 和 affine-aware
> set selection 后，强候选验证网络能否在 train-full 上学到可用候选选择，并泛化到 dev404？

这是 E-020A 的规范化后续，不覆盖 E-020A。E-020A 的结果保持为旧 G0 过严导致的 G0-stop。

## 输入与隔离

- frozen DINOv2-L full4096 K256 candidates；
- DINO checkpoint SHA：
  `d5383ea8f4877b2472eb973e0fd72d557c7da5d3611bd527ceeb1d7162cbf428`；
- official training split：train `1607` / dev `404`；
- 原始 optical/SAR `512x512` 图像；
- raw truth_flow 仅用于 train labels、dev metrics 和 oracle diagnostics；
- 禁止 OS424/confirm/datum；
- 禁止修改 DINO/GDROS checkpoint、baseline source、E-015A/E-016A/E-017A/E-018A/E-019A/E-020A artifacts。

## 网络结构

继承 E-020A 强网络语义：

- raw optical/SAR multi-scale patch evidence；
- frozen DINO local feature crop/sampling；
- candidate token；
- within-source K256 competition；
- explicit dustbin/abstention；
- source-neighbor/region graph；
- `B>=8` global/affine basin tokens；
- endpoint/source-choice/basin/residual/confidence/affine heads。

缺少任一主通道则 `IMPLEMENTATION_BLOCKED_OR_MODEL_TOO_WEAK`。

## 新 G0 规则

1/4/8 pair overfit 只做 sanity：

- 报告 AP、topM correct、selected-set affine；
- 若极端异常，reviewer 可判实现阻塞；
- 但不得仅因 4-pair 未达到 E-020A 旧阈值就停止。

G0 主门是 train-full：

- 1607 train pairs 训练完成；
- train inference 不能读取 GT；
- train threshold calibration 只能用 train；
- 至少一个预注册 no-GT track 满足：
  - endpoint@2 AP >= `0.02`；
  - correct@2 mean >= `32`；
  - P50 correct@2 >= `16`；
  - precision@2 >= `5%`；
  - selected-set affine AEPE <= `14.8 px` 或相对 E-020A train-small best AEPE `19.957` 改善 >= `25%`。

G0 未通过则不跑 dev404，状态 `TRAIN_FULL_SANITY_FAIL` 或 `IMPLEMENTATION_BLOCKED_OR_MODEL_TOO_WEAK`。

## Loss / supervision

必须至少实现并报告：

- source-choice listwise CE / sampled softmax；
- dustbin for source without positive；
- hard negative mining：同 source 高 DINO score、近 score、近 displacement、wrong basin；
- supervised contrastive / group metric loss；
- affine-aware set loss 或明确等价 differentiable surrogate；
- coverage/diversity loss；
- calibration loss。

训练标签来自 train truth_flow，不称为 teacher distillation。

## G1：dev404

G0 通过后才运行 dev404，所有 track 均 no-GT inference：

- topM：`32/64/128/256`；
- region quota：`1/2/4`；
- train-calibrated threshold；
- dynamic confidence/dustbin。

报告 endpoint@2 AP/AUROC、correct/precision、coverage、selected-set affine AEPE/CMR/PLR、failure buckets。

## 判读

- `IMPLEMENTATION_BLOCKED`：P0 失败或 reviewer blocking。
- `IMPLEMENTATION_BLOCKED_OR_MODEL_TOO_WEAK`：强网络主通道或训练链路不成立。
- `TRAIN_FULL_SANITY_FAIL`：train-full 仍学不到可用候选选择。
- `TRAIN_SIGNAL_DEV_FAIL`：train-full 过，但 dev404 失败。
- `LEARNABLE_SIGNAL_FOUND_AFFINE_FAIL`：dev 候选选择明显过对照，但 affine 仍失败。
- `USEFUL_LEARNABLE_SIGNAL_FOUND`：dev selected-set affine 明显改善 E-018A。
- `STRONG_LEARNABLE_SIGNAL_FOUND`：dev 接近进入完整 sparse affine feedback。

## Review

1. model/training/architecture/loss reviewer；
2. evaluator/protocol/leakage reviewer。

任一 blocking finding，则不得解释负面结果。
