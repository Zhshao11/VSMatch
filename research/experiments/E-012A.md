# E-012A：Geometry-aware Top128 Dynamic Compression

## 目的

E-012A 检验：

> E-011A raw-image top128 候选中已经存在几何可压缩的正确观测，能否用无 GT 的几何感知压缩/重排，
> 生成动态高纯 sparse matches，并得到可用全局 affine？

本实验只做候选压缩与 affine 输出资格验证，不启动完整 sparse affine feedback。

## 输入与隔离

- 输入：E-011A formal dev/train top128 candidate outputs，只读。
- 数据标签：official training archive 的 raw `truth_flow` 只用于 train/dev loss 与评测。
- 禁止：datum、OS424、confirm、测试集 GT、跨样本缓存。
- GDROS baseline 与 E-011A retriever/checkpoint/cache/result 全部只读。
- E-012A 新代码、cache、checkpoint、日志、结果必须位于独立 `e012a` / `E-012A` 路径。

## 关键语义绑定

- `top128` 是每个 source proposal 的 target candidate depth，不是最终点数上限。
- 最终 active set 动态决定；不得固定为 K64/K128。
- 每个 source proposal 最终最多对应一个 target；无法可靠匹配的 source 进入 dustbin、pending 或 rejected。
- 同一 target 可在中间候选阶段被多个 source 候选引用，但最终输出需报告 duplicate rate，并由几何/覆盖约束抑制重复支配。
- 输出为 best basin 的 dynamic active matches、affine matrix 和解析 affine flow。

## 方法模块

实现 `GeometryAwareTop128Compressor`：

1. 读取每个 source proposal 的 top128 candidates：source xy、target xy、rank、score、source region/scale/id。
2. 构造候选特征：rank/score、source xy、target xy、displacement、region/quadrant、target duplicate、
   local density、coverage contribution、当前 affine residual、basin score、condition proxy。
3. 维护 `B` 个 affine basin slots；建议默认 `B=4` 或 `B=8`，需报告曲线。
4. 递归 `T` 轮，建议默认 `T=3`：
   - assignment：source-candidate 到 basin/dustbin 的无 GT 概率；
   - one-source constraint：每个 source 每轮最多一个 candidate 进入同一 basin vote；
   - FP32 weighted affine solve；
   - residual feedback：用当前 affine residual、coverage、condition 更新候选/源状态；
   - active/pending/rejected 更新。
5. 最终选择 basin score 最高且满足覆盖/condition 的 basin；若无合法 basin，显式 abstain。

允许训练 compressor 或用确定性几何规则初始化；但正式 inference 不得读取 GT。

## 禁止实现

- 固定最终 K128/K64 作为主语义；
- 三点 RANSAC、穷举 affine hypotheses、恢复 131,072 hypotheses；
- dense flow state、dense GRU、hidden `4096x4096` cross-image tensor；
- full-image blind target search；
- 训练或微调 GDROS backbone/FeatureTransformer/E-011A descriptor；
- frozen S2、GDROS 或 E-011A baseline fallback；
- 使用 top128 oracle 结果追认 no-GT 失败。

## 训练目标

若使用学习模块：

- candidate loss：endpoint error `<=2 px` 为正，允许 Gaussian distance auxiliary；
- source state loss：active/dustbin/pending/rejected；
- affine loss：最终 affine flow 与 raw truth_flow 的 16x16 或 512x512 sampled EPE；
- coverage/condition regularizer：鼓励跨 region/quadrant 高纯覆盖，惩罚重复 target 支配；
- residual feedback loss：后轮应提升 active precision 或 affine EPE。

必须验证 gradient 到 compressor、basin scoring 和 assignment 模块；toy synthetic affine recovery 必须通过。

## 对照

必须报告：

- frozen S2 top64：`50.015/26/48/78`，base2px `0.05161%`，nearest `15.490/75.309 px`；
- E-011A top64：`45.879/20/44/73.7`，base2px `0.04734%`；
- E-011A top128：`68.710/34/66/106`，nearest `13.129/70.895 px`；
- E-006A candidate baseline：`66.210/33/64/98`，oracle AEPE `0.190768 px`；
- E-011A-TOP128-GEOM-DIAG oracle gap：all-hard2px LS P50/P90/P95 `0.299/0.533/0.617 px`。

## Gate

### G0：协议、隔离与实现

- E-011A top128 parity PASS。
- GDROS/E-011A read-only isolation PASS。
- candidate outputs before label join PASS。
- one-source-one-target constraint PASS。
- dynamic active size test PASS：active set size 不得恒等于 64 或 128。
- no GT inference、no OS424/confirm/datum、no hidden N2、no RANSAC/131k hypothesis tests PASS。
- weighted affine synthetic、coordinate direction、coverage/condition tests PASS。
- 至少一名定向 reviewer APPROVE。

G0 FAIL 时停止，状态 `COMPLETED / PROTOCOL_OR_IMPLEMENTATION_FAIL`。

### G1：动态 active 候选质量

dev404 上必须同时满足：

- active matched source count mean `>=64`，P10 `>=32`；
- active 2px-correct count mean `>=60`，P10 `>=31`，P50 `>=56`；
- active 2px inlier precision mean `>=35%`，P10 `>=20%`；
- 覆盖至少 3 quadrants 且至少 6 个 8x8 regions 的 pair 比例 `>=95%`。

G1 FAIL 时停止，状态 `COMPLETED / DYNAMIC_COMPRESSION_FAIL`，不得启动 G2 或救援。

### G2：无 GT affine 资格

仅 G1 PASS 后运行：

- AEPE `<=2.0 px`；
- CMR@2 `>=60%`，CMR@5 `>=90%`；
- PairLocalReady/valid `>=95%`；
- condition pass pair ratio `>=95%`；
- eval p50/p95、峰值显存、live score elements 必须报告，且无 hidden N2。

G2 FAIL 时停止，状态 `COMPLETED / AFFINE_QUALITY_OR_RESOURCE_FAIL`。

G2 PASS 时状态 `COMPLETED / GEOMETRY_COMPRESSION_READY`，等待用户决定是否进入完整 sparse affine feedback。

## 诊断

报告但不作为追认：

- B=`1/2/4/8` basin 曲线；
- T=`1/2/3/4` round 曲线；
- active threshold 曲线；
- score-only、geometry-no-feedback、single-basin、full 模块消融；
- active count vs precision vs AEPE 二维/三维曲线；
- oracle gap 到 all-hard2px 和 GT-endpoint compression oracle；
- 失败 pair 的 dominant reason：count、rank tail、candidate noise、coverage、condition、basin confusion。
