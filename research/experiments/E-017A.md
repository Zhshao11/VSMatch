# E-017A：Supervised DINO Geometry-Aware Compression

## 目的

E-017A 回答：

> 能否用 train truth_flow 监督一个网络，从 DINOv2-L full4096 topK candidates 中学会 no-GT
> candidate compression/ranking，输出可拟合高质量 affine 的稀疏跨模态匹配点？

这是有效性优先实验。DINO full4096 仍是 `resource-unqualified diagnostic`，本实验不能宣称轻量化。

## 输入与隔离

- frozen DINOv2-L full4096 candidates，checkpoint SHA：
  `d5383ea8f4877b2472eb973e0fd72d557c7da5d3611bd527ceeb1d7162cbf428`。
- K256 为 main track；K512 为 secondary headroom track。
- source proposals 继承 E-015A/E-016A DINO track。
- split 固定为 `1607 train / 404 dev`。
- raw truth_flow 仅在 candidate score/id 物化并 hash 后用于训练标签与 dev 指标。
- 禁止 OS424/confirm/datum。
- 禁止修改 GDROS、DINO、E-015A、E-016A、E-011A、E-013A baseline/cache/results。
- 禁止 finetune DINO/GDROS/FeatureTransformer。

## 候选特征

每个 source-target candidate 至少包含：

- source xy、target xy、displacement；
- DINO rank、score、score gap、per-source score z-score；
- source/target 8x8 region id、quadrant id；
- in-image / boundary flags；
- 若 cache 可安全提供 DINO token embedding，可加入 source embedding、target embedding、差值、乘积和 cosine。

若 embedding 不可用，不得阻塞实验；必须记录 disabled feature reason。

## 网络

- `CandidateScorer`：candidate MLP，输出 endpoint correctness logit、soft confidence、dustbin/source confidence。
- `AffineBasinHead`：B=`8` affine basin assignment。
- `SparseAffineCompressionNet`：
  - T=`3` recurrent rounds；
  - 每轮用 candidate/basin weights 执行 FP32 weighted affine solve；
  - 将 residual、condition、region coverage summary 反馈给 candidate scorer 和 basin head；
  - 最终每个 source 最多一个 target vote；
  - active set 动态，不固定为 128；
  - 使用 train-calibrated threshold + region-balanced quota fallback，避免过度 abstain；
  - region weights 归一化，避免单一区域支配。

禁止 dense flow prediction、dense GRU、hidden 4096x4096 compression tensor、RANSAC、三点/131k hypothesis
enumeration。

## 训练

标签：

- endpoint hard positive：candidate endpoint error <= `2 px`；
- endpoint soft target：基于 endpoint error 的 Gaussian/Huber-style soft target；
- source-level target：若 source topK 内存在 positive，则最佳 positive 为 target；否则 dustbin；
- affine/grid target：raw truth_flow。

loss：

- endpoint focal/BCE；
- source-level candidate/dustbin CE；
- basin/consensus loss；
- affine grid EPE loss；
- coverage/diversity regularization；
- calibration loss，防止全部拒绝。

必须记录每个 loss 分量，且证明梯度到达 candidate scorer、basin assignment 和 residual feedback。
toy/known-shift 必须可过拟合。

## G1：有效性判读

dev no-GT inference，分别报告 K256 与 K512。

主指标：

- AEPE、CMR@1/2/5、P95/P99；
- PairLocalReady、valid、coverage；
- active count、correct@2 count、precision；
- source region/quadrant coverage；
- condition；
- comparison to E-016A best no-GT and GT oracle。

判读：

- `STRONG_LEARNED_COMPRESSION`：K256 或 K512 任一 track 达到 AEPE `<=1.8 px`、CMR@2 `>=70%`、
  PairLocalReady `>=95%`。
- `WEAK_LEARNED_COMPRESSION`：AEPE `<=3.0 px`、CMR@2 `>=50%`、PairLocalReady `>=90%`。
- `K512_HEAVY_TRACK_ONLY`：K512 达到 weak/strong，但 K256 不达。
- `RANKING_NOT_GEOMETRY_USABLE`：ranking AUROC/AP 改善但 affine 仍未达到 weak。
- `OVER_ABSTAIN`：active mean < `32` 或 coverage pass < `80%`。
- `OUTLIER_CONTAMINATED`：active/coverage 足够但 AEPE > `3 px` 且 precision 不足。
- `NO_LEARNED_COMPRESSION_SIGNAL`：ranking 与 affine 均无明显改善。

若多项成立，优先级：
`IMPLEMENTATION_BLOCKED > STRONG_LEARNED_COMPRESSION > K512_HEAVY_TRACK_ONLY > WEAK_LEARNED_COMPRESSION > OVER_ABSTAIN > OUTLIER_CONTAMINATED > RANKING_NOT_GEOMETRY_USABLE > NO_LEARNED_COMPRESSION_SIGNAL`。
