# E-015A：Strong Cross-modal Feature Stack Diagnostic

## 目的

E-015A 回答：

> 使用更强的预训练 / foundation / 跨模态 matcher 特征，能否在 E-011A top128 或 expanded candidate
> generation 中提供有效 endpoint-correctness signal？

本实验目标是先证明有效，不以计算成本为硬约束。若使用高成本全图/大模型计算，必须标记为
`resource-unqualified diagnostic`，不得宣称轻量化。

## 阶段定位

这是 SparseGeo-GDROS 的最前端 observation / descriptor 阶段。前面只有图像读取、预处理、尺度变换
和特征编码；后续 candidate ranking、geometry feedback、active set、affine solve 都依赖本阶段信号。

## 输入与隔离

- E-011A top128 candidates：只读。
- official training archive raw optical/SAR/truth_flow：truth_flow 仅用于 label join 和指标。
- E-013A pre-feedback endpoint、E-013A final score、E-011A raw score、E-014A best signal：只读 reference。
- 外部预训练模型可下载/clone 到独立 `external_features` 或 `e015a` 路径。
- 禁止修改 GDROS/E-011A/E-013A checkpoints、cache、results。
- 禁止 datum、OS424、confirm、测试集 GT。

## 文献/模型候选

至少尝试以下类别；无法运行必须记录 disabled stub、原因和证据：

1. `foundation_dense`
   - DINOv2 ViT patch tokens，多层/多尺度；
   - OpenCLIP / RemoteCLIP / remote-sensing VFM patch tokens；
   - SAM/SAM2/MAE encoder features。
2. `cross_modal_matchers`
   - MatchAnything / matchanything_eloftr；
   - XoFTR；
   - RoMa / DKM / LoFTR-style pretrained matchers。
3. `optical_sar_specific`
   - PromptMID official code/checkpoint if available；
   - SOMA official code/checkpoint if available；
   - other optical-SAR descriptor/matcher repo found by engineering, if reproducible.
4. `fusion`
   - z-score/rank fusion across available pretrained tracks；
   - train-only linear/logistic probe over frozen feature scores，仅 diagnostic，不作为正式方法成功。

## P0：模型集成与协议

P0 必须 PASS，否则状态 `COMPLETED / IMPLEMENTATION_BLOCKED`，不得解释负面结果。

- 每个 external model 记录 source URL、commit/tag、checkpoint path、checkpoint SHA、license if available。
- 每个 unavailable model 写 disabled stub，包含不可用原因。
- 预处理记录：输入大小、通道、SAR log/normalization、mean/std、resize/crop/pad。
- feature grid -> 512 pixel xy 映射测试 PASS。
- optical source -> SAR target 方向测试 PASS。
- scores/matches 在 label join 前物化并 hash。
- no OS424/confirm/datum。
- random/shuffled/swapped controls PASS。
- model feature sanity：
  - 模型加载成功；
  - feature 非常数；
  - same-image / known-shift sanity 不劣于 random。
- 两路 reviewer：
  - feature/model integration reviewer；
  - evaluator/protocol reviewer。

## D1：E-011A top128 reranking

对每个 available track：

- 对 source-candidate pair 计算 feature similarity / matcher confidence / nearest-match confidence；
- candidate-level AUROC、AP、AUPRC；
- positive/negative score quantiles；
- per-source positive rank；
- global topK K=`8/16/32/64/128/256`；
- per-region quota q=`1/2/4/8`；
- 与 E-013A pre-feedback endpoint、E-011A raw score、E-014A best non-reference、random 对比。

## D2：expanded / independent candidate generation

若 track 支持 dense retrieval 或 matcher output，额外评估：

- S1 union 内 retrieval；
- 若可承受，full 4096 target tokens retrieval；
- matcher direct correspondences；
- correct@2px count mean/P10/P50/P90；
- precision、coverage、nearest distance；
- oracle affine AEPE/PLR if sufficient candidates。

该部分允许高成本，但必须报告 live score elements、time、memory，并标为 `resource-unqualified`。

## 判读

给唯一主判读，可附 secondary：

- `STRONG_SIGNAL_FOUND`：至少一个强特征 track dev AP `>=0.01`，且 best topK/quota correct mean `>=10`、
  precision `>=2%`，并明显超过 E-013A pre-feedback endpoint。
- `WEAK_SIGNAL_FOUND`：超过 E-013A pre-feedback endpoint，但未达到 strong。
- `MATCHER_CANDIDATE_FOUND`：expanded/direct candidate generation 的 correct coverage 明显超过 E-011A
  top128 或 E-006A baseline，即便 top128 reranking 一般。
- `NO_STRONG_FEATURE_SIGNAL`：所有强特征不超过 E-013A pre-feedback 或无法转化为 topK/quota correct。
- `IMPLEMENTATION_BLOCKED`：P0 或 reviewer 未通过。
