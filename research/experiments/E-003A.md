# E-003A：冻结 GDROS 的轻量几何 Learned Selector

方法：`M001 v0.6`

状态：`READY`

## 1. 研究问题

在冻结 GDROS post-Transformer 特征和 cosine top8 candidate set 的情况下，能否以小型
`O(TNK)` selector 学会候选权重、仿射几何反馈和失败置信度，使开发验证集精度逼近
top-k oracle，同时保持 SparseGeo 的低显存、低延迟收益。

本实验只做 train/dev feasibility，不运行最终确认测试，不读取 OS 424 标签。

## 3. 冻结候选前端

- E-003A train/dev 保持 official archive 解码后的 `512x512` 原图；不调用 `FlowAugmentor`，
  不 resize、crop、flip 或改变宽高。512 经过冻结 stride-8 前端得到 `64x64=4096` target tokens。
- 使用官方 GDROS OS checkpoint，全部参数 `requires_grad=false`，model `eval()`。
- feature forward 必须位于 `torch.no_grad()`，不得保存反传图。
- 使用 E-002A/E-002B 的 post-Transformer stride-8 feature hook。
- optical 为 source，SAR 为 target，flow 为 `target-source`。
- anchors 固定为 E-001 `public_stratified` 映射后的 K128 stride-8 token。
- 每个 anchor 对 64x64 target token 只计算 cosine top8；tie-break 与冻结实现一致。
- 不构造 source-all x target-all correlation，不产生 hypothesis/triple 维度。

允许离线缓存每对的 128x8 candidate table；缓存只能含无 GT candidate features。训练标签存放
在独立文件并受 split allowlist 控制。至少 2 对须在线重算并逐元素验证缓存 parity。

## 4. 主模型

### 4.1 Candidate encoder

对每个 `(source anchor i, candidate j)` 构造无 GT 特征：

- cosine score、0-based rank、相对 top1 margin、相邻 rank score gap；
- source/target 归一化坐标和二维位移；
- source/target descriptor L2 norm 的 `log1p`；
- target token 在全部 128x8 candidate table 中的 multiplicity。

共享 MLP hidden width 固定为 64，激活 GELU；参数总数必须报告并小于 100,000。每个 anchor
额外预测一个 dustbin logit。

### 4.2 两轮几何反馈

主配置 `T=2`。每轮：

1. 对 8 candidate logits + dustbin 做 per-anchor softmax。
2. 使用非 dustbin 概率，在 `[-1,1]` 归一化坐标中执行 FP32 weighted affine solve。
3. 计算每个 candidate 相对当前 affine 的二维 residual、L2 residual 和当前权重。
4. 用共享 residual-update MLP 更新 logits。

第二轮输出最终 affine，不进行第三轮拟合。求解必须显式处理退化、non-finite 和 condition；
失败时输出结构化 abstention，禁止 baseline fallback。

加权求解固定使用 candidate 概率作为权重，构造
`(X^T W X + 1e-4 I) H = X^T W Y`，FP32 Cholesky 求解。若 Cholesky 失败、输出 non-finite
或 `cond(X^T W X + 1e-4 I) > 1e6`，该 pair 结构化 abstain。不得改用 GT、baseline 或第三次拟合。

### 4.3 Confidence

从 dustbin mass、effective anchor count、weighted residual mean/std/max、四象限权重覆盖和
solver condition 的池化统计预测 `softplus` grid error。训练目标为 stop-gradient 的真实
16x16 full-image affine grid error。推理固定规则：预测 grid error `>5 px` 则 abstain。

## 5. 训练目标和预算

- 监督的唯一权威是每对原始 `truth_flow/*.flo`，方向固定为 `target-source`。`datum/*.npy`
  只参与 archive 完整性和文件 SHA，不得加载为 candidate、affine、loss、confidence 或指标标签，
  也不从 truth_flow 另行拟合 GT affine。
- candidate target：source token `(xf,yf)` 对应 source pixel `(8xf,8yf)`；在 raw truth_flow
  的该整数像素直接读取位移 `(du,dv)`，得到 target pixel `(8xf+du, 8yf+dv)`，再除以 8 得到
  stride-8 GT target location。该直接索引等价于下面固定采样器在整数位置的结果。
- 固定 truth-flow 采样器：`torch.nn.functional.grid_sample`，`mode="bilinear"`、
  `align_corners=True`、`padding_mode="zeros"`，像素 `(x,y)` 映射到
  `(2*x/511-1, 2*y/511-1)`。候选 anchor 均在图内；GT target 越界仅决定 dustbin 标签。
- candidate target 在 stride-8 target 坐标中计算 top8 距离；最近
  candidate 超过 2 token 或 GT target 越界时目标为 dustbin，否则以固定 `sigma=0.5 token`
  的 `exp(-d^2/(2 sigma^2))` 归一化为 top8 距离软标签，dustbin target 为 0。
- `L_candidate`：top8+dustbin cross entropy。
- `L_grid`：固定 16x16 grid 为 `x,y = linspace(0,511,16)` 的 Cartesian product。预测 affine
  在这些 source pixel 上解析产生 displacement；raw truth_flow 按上述固定 bilinear 采样器读取。
  两者二维 endpoint error（pixel）除以 8 后使用 Charbonnier，`epsilon=1e-3`。
- `L_conf`：`actual grid error` 唯一定义为上述 256 个点的二维 endpoint error 像素均值；
  `log1p(predicted grid error)` 对 stop-gradient `log1p(actual grid error)` 使用 SmoothL1。
- 总损失固定为 `L_candidate + L_grid + 0.2 * L_conf`。

主训练：AdamW，lr `1e-3`，weight decay `1e-4`，batch `64`，最多 `100` epochs，dev grid
mean patience `10`。主 seed `20260805`；seed `20260806/20260807` 仅报告稳定性，不得替换主结果。
训练仅更新 selector。保存每 epoch train/dev 分量、梯度 norm、学习率、checkpoint 和资源记录。

## 6. 对照和消融

主结果只看 `learned-main-T2` 主 seed。必须同表报告：

- 冻结 `E-002B C8-main`；
- `learned-unary-only`：相同 candidate encoder，无 affine residual feedback；
- `nonlearned-soft-EM/GNC`：固定无训练鲁棒重加权；
- `learned-main-no-abstention`：同一输出但强制全覆盖；
- `learned-main-T2`：正式主配置。

消融只能解释组件，不能在 dev 结果后替代主配置。禁止 hidden width、T、K、top-k、loss weight、
温度或阈值搜索。

`nonlearned-soft-EM/GNC` 固定为两次求解：初始每 anchor 权重为 `softmax(cosine/0.1)`；第一次
仿射后，使用 `softmax(cosine/0.1 - 0.5 * min((residual_token/2)^2, 9))` 更新权重并做第二次
相同 FP32 加权求解。它不含 learned 参数、dustbin、confidence 或额外迭代。
