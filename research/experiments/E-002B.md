# E-002B/B2-bridge：source-aware top-k 仿射共识

方法版本：`M001 v0.4`

执行任务：`019fc85d-350e-7941-ac69-89c626641fd9`

状态：`IMPLEMENTING / EFFICIENCY_HOLD`

规范绑定：`BIND-001`。在查看任何 E-002B accuracy 结果前，固定唯一-target 后的排序求和域
和两轮 LS 后的 final validation 语义；详见第 6、7 节。

## 1. 决策依据与解释边界

E-002A 的正式状态保持 `COMPLETED / EFFICIENCY_HOLD`，门槛为
`G0 PASS; G1/G2/G3/G4/G5 FAIL`。本实验不得把 G3 追认为通过：cosine 的
`R@8,r1 / R@32,r1 / R@64,r2` 为 `26.3970 / 46.9063 / 79.4373%`，低于预注册的
`40 / 65 / 80%`。

选择 B2-bridge 的原因不是 top-k 检索已经过门槛，而是其余三个方向缺少进入条件：

- B1：top1 recall、confidence AUROC 和 top32 precision 均不足。
- B3：GT-in-bounds 对 PairLocalReady 的提升为 `0 pp`。
- learned descriptor：冻结检索判负三条件未同时成立；top64 select-and-reject oracle 的
  PairLocalReady 仍为 `100%`。

候选级几何是当前唯一尚未验证、同时又有正 oracle 的冻结特征机制。top8
select-and-reject oracle 的 raw/cosine PairLocalReady 为 `99.2925 / 99.5283%`，但 top8
select-all 仅为 `1.1792 / 2.3585%`。因此研究问题严格限定为：无 GT 的 source-aware
仿射共识能否从一对多候选中选择并拒绝正确集合。

本轮是 feasibility bridge，不单独主张创新，不启动训练，不进入局部亚像素精修。

## 2. 冻结输入与不变量

完全复用 E-002A 已审阅路径：

```text
optical/SAR [1,3,512,512]
  -> BasicEncoder
  -> converter
  -> FeatureTransformer
  -> post-Transformer [1,256,64,64]
  -> K128 public-stratified source anchors
```

以下内容不可改变：

- 使用同一 released checkpoint、官方 preprocessing 和 slim-execution feature wrapper。
- optical 是 source，SAR 是 target，flow 为 `target-source`。
- stride-8 token `(xf,yf)` 对应像素 `(8xf,8yf)`。
- anchor map 与 E-002A K128 完全相同，JSON 和 SHA256 必须一致。
- 所有仿射求解使用 `[-1,1]` 归一化坐标和 FP32；输出按 E-002A 的矩阵共轭解析成
  `512 x 512` dense flow。
- 正式方法不使用 GT、valid mask、黑边过滤、可见性、测试标签或 baseline flow。
- 最终 AEPE/CMR 继续在完整图像上无 mask 评测，黑边参与。
- 不执行 context encoder、CorrBlock、GRU、upsampler 或 cost-perceiver。
- 不构造 `4096 x 4096` cross-image correlation。

## 3. 候选定义

主分数固定为 cosine：source/target feature 逐 token L2 normalize，再计算
`K x 4096` cosine scores。选择 cosine 的依据仅是 E-002A 已预注册的 raw/cosine 对照中，
cosine 在各级 recall 和 hard 解码 AEPE 上一致优于 raw；这不表示 cosine 已通过 G2/G3。

候选稳定排序规则：分数降序；分数完全相同时按 target row-major index 升序。chunked 和
unchunked top-k 必须返回完全相同的 index，score 最大差不超过 `2e-5`。

预注册配置：

| ID | score | seed candidates | scoring/refit candidates | 角色 |
| --- | --- | ---: | ---: | --- |
| `C8-main` | cosine | 8 | 8 | 主实验 |
| `C8-consensus-only` | cosine | 8 | 8 | 去掉重指派的归因对照 |
| `C8-C16-diagnostic` | cosine | 8 | 16 | 候选保留量诊断 |
| `R8-diagnostic` | raw-dot / 16 | 8 | 8 | score 诊断 |

top16 诊断只扩展假设评分与重指派的候选集合；仍由 top8 生成假设，禁止事后把 top16 改成
主结果。温度、dual-softmax、local soft-argmax、1/16 特征均不进入 E-002B。

## 4. Anchor-balanced 三点组 bank

仿射最小样本为三个 source anchors。三点组 bank 只由固定 K128 source 几何生成，与图像、
特征、候选分数和 GT 无关，所有 424 对复用同一个 bank。

1. 将 source lattice 按 `x<32 / x>=32` 和 `y<32 / y>=32` 分为四象限。
2. 枚举全部 source 三点组合；要求三个点来自三个不同象限、归一化设计矩阵 rank 3、
   condition number `<=10`。
3. 以 anchor 使用次数全零开始，确定性贪心选择 256 个不重复三点组。每步对剩余三点组按
   以下字典序取最小：三点中最大累计使用次数、累计使用次数之和、负三角形面积、三个
   anchor row-major index。
4. 选择后给该组三个 anchor 的使用次数加一。
5. 保存 ordered bank、每个 anchor 使用次数、条件数、面积、生成器版本和 SHA256。

必须测试 bank 恰好 256 组、覆盖全部 K128 anchors、每组满足三象限/rank/condition 条件，
且重复生成的字节和 SHA256 一致。

方法任务已使用 E-002A 正式归档的相同 anchor map 做只读预检：共有 104,781 个合法候选
三点组；上述贪心规则得到 256 组，覆盖 128/128 anchors，每点使用 5-7 次，最大 condition
为 `9.218973`，最小三角形面积为 `84.0 cell^2`。sentinel 32 点覆盖四象限、rank 3、
condition `2.350616`。该预检只证明规范可执行，不能替代实验任务的独立单测和 SHA 产物。

## 5. 仿射假设生成

对 bank 中每个 source 三点组，穷举三点各自 top8 target candidates 的全部 `8^3=512`
rank 组合，理论上限为 `256 x 512 = 131,072` 个假设。target 三点必须互异且非共线；不满足
时跳过并记录原因。

source 三点归一化设计矩阵的逆可预计算。每个 target 组合在 FP32 中解析得到一个 source 到
target 的六参数仿射。除 finite、target 互异和非共线外，不使用旋转、尺度、平移、行列式或
in-bounds 先验过滤，避免把数据集 GT 分布隐藏进求解器。

假设必须分块流式生成，`hypothesis_chunk <=256`。禁止物化全部假设对应的
`H x K x L` residual cube。

## 6. 两级无权重几何共识

对仿射假设 `H`、source anchor `i` 及其候选 `y_ir`，在 stride-8 target lattice 单位定义：

```text
d_i(H) = min_r || project(H, x_i) - y_ir ||_inf
```

先为当前 scoring set 中每个 source anchor 保存原始 assignment
`a_i=(target_i,d_i,rank_i)`，candidate rank 使用从 0 开始的整数 `0,...,L-1`。多个 source
anchors 选择同一个 target token 时，只保留 residual 最小者；再并列时保留 source index
更小者。唯一-target 去重后的 surviving source 集记为 `U(H)`。

同一个 source anchor 最多贡献一票，只有 `U(H)` 能进入 inlier/support 计数。为防止模型
通过 target collision 删除困难 source 并降低后续代价，对全部当前 scoring anchors 定义：

```text
tilde_d_i = d_i      if i in U(H), else +inf
tilde_r_i = rank_i   if i in U(H), else L
```

因此，被 collision 抑制的 source 不投票，但在截断 residual 中按 outlier cost `4`、在 rank
中按比最差合法 rank 再差一级的 `L` 计入。这里“全部”指当前 scoring set：coarse 阶段为
32 个 sentinels，full rerank 和 final validation 为全部 K128 anchors。

每个假设使用以下固定字典序排序，不引入连续融合权重：

1. `i in U(H)` 且 `d_i <= 1` 的唯一 source/target inlier 数，降序；
2. inlier 覆盖的 `4 x 4` source macro-cell 数，降序；
3. `i in U(H)` 且 `d_i <= 2` 的唯一 source/target support 数，降序；
4. 对当前 scoring set 的全部 source anchors 求 `sum_i min(tilde_d_i^2,4)`，升序；
5. 对当前 scoring set 的全部 source anchors 求 `sum_i tilde_r_i`，升序；
6. 全局 hypothesis ID，升序。

两级验证固定为：

- coarse sentinels：K128 ordered anchor list 的 `[0,4,8,...,124]`，共 32 点；必须验证覆盖
  四象限且 rank 3。
- 对全部流式假设做 coarse score，只保留全局 top `Q=1024`。
- 用全部 K128 anchors 对 Q 个假设重排，只保留 top `R=32` 进入重指派。

`C8-consensus-only` 直接输出 full-score 最优假设，不执行下一节。

## 7. 候选重指派与普通 LS

对 full-score 前 32 个假设分别执行两轮：

1. 将 H 投影到全部 K128 source anchors。
2. 每个 anchor 选择几何 residual 最小的允许候选；并列时按 candidate score 降序、target
   index 升序。
3. 只保留 `L_inf residual <=2` 的候选，并按 residual 最小原则做 target 一对一去重。
4. 要求至少 12 个唯一对应、覆盖至少 3 个象限、归一化设计 rank 3 且 condition `<=20`。
5. 在保留对应上做 FP32 ordinary LS，更新 H。

第二轮 ordinary LS 更新 H 后，必须额外执行一次只校验、不再拟合的 `final validation`：

1. 使用更新后的最终 H，重新执行本节第 1-3 项 assignment、`L_inf<=2` 过滤和唯一-target
   去重。
2. 用这次 final validation 的 surviving correspondences 重新计算对应数、象限覆盖、rank 和
   condition；不得沿用第二轮 LS 输入对应的旧统计。
3. final validation 对应不少于 12、覆盖至少 3 象限、设计 rank 3 且 condition `<=20` 时，
   该最终 H 才有效；此步不再调用 LS 或更新 H。
4. 对有效的最终 H 按第 6 节在全部 K128 anchors 上重算完整字典序，选择最终输出。

主路径不使用 appearance WLS、Huber、Student-t 或其他 IRLS；这些必须在 B2 候选选择已被
证明有效后作为独立版本加入。

若没有假设通过 final validation，方法必须标记 `abstained=true`，dense contract 输出
identity affine，并将该 pair 计入失败率。禁止静默回退到 GDROS baseline、GT oracle 或
hard-top1 结果。

## 8. 实现与 GT 隔离门槛

正式运行前必须通过：

- E-002A slim/reference feature parity 仍为精确 0。
- C8/C16 chunked/unchunked top-k index 完全一致，score 最大差 `<=2e-5`。
- 三点组 bank、sentinel list、hypothesis ID 和全部 tie-break 可重复。
- synthetic affine：向每个 top8 set 注入一个已知对应并加入 7 个离群候选，主算法在不少于
  100 个固定 synthetic cases 上恢复 H；lattice grid mean `<=1e-3 cell`，无 solver failure。
- target 重复、候选并列、target 共线、少于 12 inliers、三象限不足和 singular LS 均有
  明确单测。
- 单测必须证明 collision 被抑制的 source 在排序键 4 中贡献 cost `4`、在键 5 中贡献 `L`；
  coarse/full 使用各自 scoring set 的全部 anchors，不能只对 survivors 求和。
- 单测必须构造“第二轮 LS 输入有效但更新后 final assignment 无效”的 case，确认最终结果
  abstain；final validation 不得触发第三次拟合。
- 所有正式 variant 标记 `uses_ground_truth=false`；GT 构造只能发生在最终方法输出完成后。
- 正式路径不得 import 或调用 E-002A 的 GT-only candidate selector。

单测、2 对 smoke、规范到代码模块映射和独立子 agent 实现审阅全部通过后，才能进入资源
复核和正式 accuracy。

## 9. 资源复核与 hold 解除

E-002A 的 G5 结果永久保持 FAIL；不得删除 r2 进程或用理论复杂度追认通过。E-002B 使用
预注册的 `G5-R v0.4` 做新一轮资源资格审查：

1. RTX 4090、batch 1、512x512、FP32、eval/inference mode、输入预驻留 GPU。
2. baseline 与 B2 dense-contract 各 5 个新进程；每进程 20 warm-up、200 measured；每次
   CUDA synchronize，保存 wall/CUDA Event 原始数据。
3. B2 dense-contract p50 `<=50 ms`、p95 `<=63 ms`，五进程 p50 CV `<=5%`，不得剔除进程。
4. cold/warm peak allocated 均 `<=284 MiB`；竞争目标仍为 p50 `<=30 ms`、峰值
   `250-270 MiB`。
5. K128 score 实际元素严格为 `128 x 4096`，候选 score 增量不超过 8 MiB；假设分块和
   reranker 的 live tensor shape 全部记录。
6. 不存在 cross-image `4096 x 4096`，也不重新启用旧模块。
7. K-scaling 重新测量时将 target contiguous/layout 准备与 matcher core 分开；core 使用
   K=`64,128,256,512,1024`、预驻留连续 feature、至少 100 次 inner repeat 放大信号。
   要求 score count 精确线性、incremental peak memory 线性 R2 `>=0.99`，timing 正斜率且
   R2 `>=0.90`。K512/1024 只作复杂度诊断，不属于部署配置或 8 MiB 门槛。
8. 另报告 reranker 单独 p50/p95、假设生成数、coarse/full/refit 分段耗时和吞吐。

只有全部 G5-R 条件通过，才解除当前 `EFFICIENCY_HOLD`。可以先实现和审阅 accuracy 路径，
但 G5-R 未通过时不得启动 424 对正式 accuracy，也不得进入 E-002C。

## 10. Accuracy 门槛与报告

正式数据保持官方 424 对、同一 checkpoint、完整无 mask 评测。参数和 tie-break 已由本文
锁定，禁止依据 424 对结果改变 L、T、Q、R、阈值、迭代数或 score。

E-002B 是依据 E-002A 在同一 424 对上预注册的分层诊断所做的自适应后续实验。因此其
424-pair 结果可用于验证公开协议下的机制可行性和与 E-000 的同协议比较，但不能单独表述为
完全未见测试集上的最终泛化结论。论文定稿前，锁定配置还必须在未参与本轮分支选择的
optical-SAR 数据或预先隔离的官方训练/验证 split 上做一次 confirmatory evaluation。

主门槛只看非 GT `C8-main`：

- 至少 `90%` pairs 满足 E-002A 原定义的 `PairLocalReady`；
- 至少 `90%` pairs 非 abstention，且 final validation 对应不少于 12、覆盖至少 3 象限、
  condition `<=20`；
- 16x16 grid mean 的全数据均值 `<=8 px`；
- 所有 pair finite，无静默 solver failure；
- G5-R 全部通过。

完整报告：AEPE、CMR@1/2/5、pair P50/P95/P99、failure/abstention、PairLocalReady、grid
mean/P95、corner max、capture@32、最终 inlier 数/象限/macro-cell/condition、候选 rank
分布、target collision、hypothesis support margin，以及 image-pair bootstrap 95% CI。

必须同时报告 E-002A cosine hard-top1、`C8-consensus-only`、`C8-main`、
`C8-C16-diagnostic`、`R8-diagnostic` 和相同 top-k GT oracle；GT oracle 只能标记上限。

## 11. 后续决策与停止条件

```text
G5-R FAIL
  -> 保持 EFFICIENCY_HOLD，返回方法任务；不运行正式 accuracy

C8-main PairLocalReady >=90% 且其余主门槛通过
  -> B2-bridge PASS，返回方法任务设计 E-002C

C8-main FAIL，但任一预注册 diagnostic 达到主门槛
  -> 不自动提升 diagnostic；返回方法任务形成新版本并解释 score/L 变化

全部非 GT 变体 FAIL
  -> 审计 bank、假设命中率、support separation、重指派和 oracle gap；不自动转 learned descriptor
```

只要 top-k select-and-reject oracle 仍高，B2-bridge 失败只能否定当前固定共识选择器，不能
否定冻结 feature candidate set 或整个 SparseGeo 方法族，也不能写入 `FAILED_METHODS.md`。
learned descriptor 仍须满足 M001 v0.3 的完整三项判负条件，并在独立 validation 或外部数据
上复核后另立方法版本。
