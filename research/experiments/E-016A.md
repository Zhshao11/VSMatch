## D1：topK 与分布曲线

K 固定为 `8/16/32/64/128/256`。每个 K 报告：

- candidate count；
- correct@1/2/5 proposals mean/P10/P50/P90；
- nearest endpoint distance P50/P90；
- candidate base rate；
- unique source with at least one correct candidate；
- first-correct rank histogram；
- 8x8 source-region coverage；
- quadrant coverage；
- target unique count、duplicate ratio；
- per-pair failure bucket。

## D2：no-GT score selection baseline

仅使用 DINO score/id，不使用 GT，报告：

- per-source top1 by DINO score；
- global topK by DINO score；
- 8x8 region-quota score selection，quota=`1/2/4/8`。

每个 selection 输出 affine AEPE、CMR@1/2/5、P95/P99、PairLocalReady、condition 和 coverage。

## D3：GT-guided compression oracle

GT 只作为 oracle 诊断，不得进入正式 inference。

1. Per-source best oracle：
   - 对每个 source proposal，仅保留 endpoint error 最小的一个 candidate；
   - 分别统计 `hard2px` 和 `hard5px`。
2. All-hard ordinary LS：
   - 使用所有 per-source best 且 endpoint error <= threshold 的 candidates。
3. Region-balanced budget oracle：
   - 先在每个 source 内取 endpoint error 最小 candidate；
   - 仅保留 endpoint error <= threshold；
   - 按 8x8 source region row-major 轮询，每个非空 region 每轮最多选 1 个；
   - region 内排序键为 `(endpoint_error, dino_rank, source_id, target_id)`；
   - 轮询直到 budget B=`16/32/64/128/256` 或候选耗尽；
   - 对选中点普通 FP32 LS 拟合 affine。

输出 affine AEPE、CMR@1/2/5、P95/P99、PairLocalReady、condition、effective points、
source-region/quadrant coverage。

## 判读

唯一主判读，可附 secondary：

- `DINO_GEOMETRY_COMPRESSIBLE`：GT-guided hard2px 或 region-balanced oracle 在 K<=256、B<=128 下达到
  AEPE `<=1.6 px`、CMR@2 `>=75%`、PairLocalReady `>=95%`。
- `RANK_TAIL_LIMITED`：K256 的 GT-guided oracle 明显通过但 K128 不通过，或 K256 correct mean 比
  K128 高 `>=30`。
- `SOURCE_TARGET_DIVERSITY_LIMITED`：GT positives 集中在少数 source region/quadrant 或 target duplicate，
  导致 coverage/condition 不达标。
- `NO_GT_COMPRESSION_LIMITED`：GT-guided oracle 能通过，但 no-GT score/region selection 完全不能接近。
- `OBSERVATION_STILL_LIMITED`：即使 GT-guided oracle 也不能通过。
- `IMPLEMENTATION_BLOCKED`：P0 或 reviewer 未通过。

若多项成立，优先级为：
`IMPLEMENTATION_BLOCKED > OBSERVATION_STILL_LIMITED > RANK_TAIL_LIMITED > SOURCE_TARGET_DIVERSITY_LIMITED > NO_GT_COMPRESSION_LIMITED > DINO_GEOMETRY_COMPRESSIBLE`。
