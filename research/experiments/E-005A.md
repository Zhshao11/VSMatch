# E-005A：稀疏递归仿射共识

方法：`M001 v0.8`

状态：`READY_FOR_IMPLEMENTATION`

## 1. 研究问题与停止边界

验证能否以 M256 稀疏跨模态候选、集合级递归共识和六自由度 affine state，替代 GDROS 的
`4096x4096` correlation、dense flow hidden state 和 dense GRU，并在独立 dev 上同时接近 dense
GDROS 精度、显著降低推理成本。

E-005A 是一个新主实验，不是 E-004A rescue。任一预注册 gate 失败后写 `RESULT_CARD.md` 并停止；
不得自动建立 E-005B、微调 descriptor、加入 RANSAC/IRLS/BA、恢复 dense flow 或调用 baseline。

## 4. M256 与一次性 Global Candidates

完全复用 E-004A 的 `8x8` regions 和每区 offsets
`{(2,2),(2,6),(6,2),(6,6)}`，按 `(region_id,proposal_id)` 排序，共 M256 source anchors。

source/target descriptors L2 normalize。分块计算精确 `256x4096` cosine，按 `(-score,target_id)`
确定性取 L8。该 global search 每 pair 只执行一次；禁止 materialize `4096x4096`、对未进入 M256
的 source 做 target search，或在递归轮间重新执行 global search。

每个 candidate 初始连续 target 坐标为其 stride-8 整数 token `(x,y)`。静态输入为：source/target
descriptor 的 elementwise product 与 absolute difference 的 learned projection、cosine score、rank、
source/target normalized xy 和 normalized displacement。candidate hidden dim `D=96`。

初始 candidate logits 为 `cosine/0.1`，每 anchor 的初始 dustbin logit 为一个共享可训练标量。
初始 affine `H0` 为 normalized-coordinate identity；第 1 轮 geometry-residual feature 显式置零，
不得以错误的 identity residual 排斥大位移 candidate。

## 5. Sparse Local Correlation

每轮对全部 `256x8` continuous candidates 采样 target post-Transformer feature。采样 offsets 固定为
Cartesian `{-0.5,-0.25,0,0.25,0.5}^2` stride-8 token，共 25；`grid_sample` 使用 bilinear、
`align_corners=True`、zero padding。与对应 source descriptor 做 cosine，得到 25 维 local evidence。

candidate coordinate head 输出二维值，更新为
`q(t+1)=q(t)+0.5*tanh(delta(t))`，因此每轮每轴最多移动 0.5 token。越界坐标不 clamp；zero padding、
越界标志和可见性由模型处理。静态 score/top8 ID 不随 coordinate 更新改变。

理论 sample count 必须严格为 `T*M*L*25 = 204,800`。禁止 dense unfold、完整 local cost volume 或
跨 candidate 共享错误的 pair cache。

## 6. Setwise Recurrent Consensus

固定 `T=4, D=96, G=16, heads=4`，四轮共享全部更新参数：

1. 每 anchor 以当前 candidate probability 对 8 个 candidate hidden 加权汇总，并加入 source
   projection、dustbin probability、entropy、top1 margin、当前 active flag。
2. 16 个 persistent learned global tokens cross-attend M256 anchor summaries，再做 G16 self-attention；
   M256 anchors 只 cross-attend G16，不允许 M256 self-attention。
3. 每个 candidate 以共享 `GRUCell` 更新 hidden；输入包含 local 25 scores、所属 anchor context、
   global context、当前 coordinate、上一轮 logit，以及 `q-Hp` 二维 residual 和 residual norm。
4. 第 1 轮 residual 输入为零；第 2-4 轮使用上一轮 affine。heads 输出 coordinate delta、8 个
   candidate logit increments、一个 dustbin increment 和一个 anchor reliability logit。
5. global tokens、candidate hidden 和 logits 均跨轮保留；不得每轮重新初始化。

global-token attention 只允许 `O(MG+G^2)`；candidate 内部操作只允许 `O(ML)` 或每 anchor
`O(L^2)`。实现必须记录每轮 shape、调用计数和 active-set 变化。

## 7. Dynamic K128 与 Weighted Affine

每轮令 `r_i=(1-p_dustbin_i)*sigmoid(reliability_i)`。以 E-004A 的确定性 allocator 重选 active K128：

1. 每个 region 先取最高 `r_i` 的一个 anchor，共 64；
2. 其余按 `(-r_i,region_id,proposal_id)` 全局补齐；每区最多 3；
3. 最终严格 K128，每区 `[1,3]`；下一轮允许 inactive/active 相互替换。

对每个 active anchor，将非 dustbin probabilities 条件归一化，得到 continuous target expectation
`qbar_i=sum_l p_il*q_il/sum_l p_il`；权重
`w_i=max(1e-6,(1-p_dustbin_i)*sigmoid(reliability_i))`。

source/target 从 stride-8 coordinates 统一转为 `xn=2x/63-1, yn=2y/63-1`。构造
`X_i=[xn_i,yn_i,1]`，使用 FP32 `torch.linalg.lstsq(sqrt(w)X,sqrt(w)Q)` 分别求 target x/y；
不加 ridge、不 detach、不 IRLS。记录 weighted `X^T X` condition 和 effective sample size
`(sum w)^2/sum(w^2)`。condition `>20`、ESS `<12` 或非 finite 时显式 abstain；不得 fallback。

最终 `H4` 是唯一部署几何输出。解析 `512x512` affine flow 时完成 feature-normalized -> pixel
coordinate 共轭，再按 `target-source` 生成 flow；公开指标逐像素 Euclidean EPE、无 mask、含黑边。

## 8. 监督与训练

anchor GT target 在 source pixel `(8xf,8yf)` 直接读取 raw truth_flow，再除以 8 得到 feature 坐标。
初始 top8 中离 GT 最近且 L2 `<=2` tokens 的 candidate 是 class target；否则为 dustbin。该标签只在
train/evaluator 生成，绝不进入 inference trace。

每轮损失：

- `L_candidate`：9-way class-balanced cross entropy，权重 `1.0`；
- `L_reliability`：anchor recoverable class-balanced BCE，权重 `0.5`；
- `L_coordinate`：仅正确 candidate 到 continuous GT target 的 SmoothL1，权重 `1.0`；
- `L_affine`：`16x16 linspace(0,511,16)` grid 的 normalized-coordinate L1，权重 `2.0`。

四轮时间权重固定为 `[0.125,0.25,0.5,1.0]`，除以权重和。不得新增 loss、改变权重或根据 dev
结果修改 T/D/G/L/M/K/local window。

只训练 E-005A 新模块。AdamW，lr `2e-4`，weight decay `1e-4`，pair batch 8，最多 60 epochs，
gradient clip 1.0；以 dev affine grid error、patience 8 early stop。AMP 可用于网络，top8 tie、
affine solve 和公开 metrics 必须 FP32。主 seed `20260808`，复核 seed `20260809`。

## 10. Gate

### P0：Oracle 与静态预算

完整 dev 上，在不训练的 evaluator 中对每个 M256 top8 选择 GT-nearest candidate，并允许在四轮
总计每轴 2-token 可达范围内落到 GT-nearest quarter-token lattice；随后按 GT recoverability 和
固定 tie-break 选择 coverage K128，ordinary affine：

- AEPE `<=1.6 px`，PairLocalReady `>=99%`，valid affine pairs `>=99%`；
- exact top8/global/local counts、coordinate direction、full-image no-mask metric 全部 PASS；
- 静态图无 `4096x4096` tensor、dense flow state、dense GRU、hypothesis 或 forbidden module。

P0 只证明候选与局部坐标的可达上限，不能作为部署精度。失败则不训练。

### G0：实现资格

- 全部自动测试、toy overfit、checkpoint save/load 和两个 seeds 的 deterministic startup PASS；
- 创新模块 local update/global consensus/candidate logits/reliability/affine loss 梯度均 finite nonzero；
- 两轮 reviewer `APPROVE/APPROVE`；第三方 commit/license/provenance 完整；
- inference trace 无 GT/datum/OS424、fallback、hidden N2 或跨 pair cache。

### G1：Dev 精度

主 seed、完整 404 dev、无 GT inference：

- AEPE `<= max(2.0 px, dense-GDROS-dev AEPE + 0.35 px)`；
- PairLocalReady `>=99%`；CMR@2 相对 dense-GDROS-dev 下降不超过 `3 pp`；
- valid/non-abstention pairs `>=99%`，grid mean `<=2.5 px`；全部输出 finite；
- 复核 seed 在 AEPE、PairLocalReady 和 CMR@2 上与主 seed 同方向，不得替代主 seed。

报告每轮 candidate accuracy、recoverable active count、active replacement rate、affine condition/ESS、
grid/AEPE、dustbin calibration；报告全部 ablations，但只以 full model 判 gate。若 full model失败，
不得以 ablation 或另一个 seed 追认。

### G2：资源

独立进程、batch1、warmup 20、measured 200、每次前后 CUDA synchronize，保存 raw rows：

- global scores 严格 `256x4096` 一次；local samples 严格 `4x256x8x25`；无 hidden N2；
- 从 frozen features 开始的 E-005A core p50/p95 `<=10/15 ms`，incremental allocated `<=96 MiB`；
- 从 decoded GPU images 开始的 slim end-to-end p50/p95 `<=25/35 ms`；
- 同进程 frozen dense GDROS p50 speedup `>=3x`；warm allocated `<=284 MiB`；
- 5 fresh processes p50 CV `<=5%`，报告 cold/warm peak、参数量和各 phase 同步诊断。
