# E-022A：Candidate Feature Discriminability

方法版本：`M001 v2.6 diagnostic`

状态：`USER_APPROVED / READY_FOR_ENGINEERING`

## 1. 问题

E-021A 的 selected-set enrichment 已有信号，但无法形成可用点集：train-full best track `expected_top256`
的 enrichment@2 为 `32.2557x`，但 precision@2 仅 `1.3979%`、correct@2 mean/P50 为 `1.919/1`、
AEPE `32.405 px`。这说明“候选池里有好点”和“selector 能挑出足够好点”之间仍缺一层强区分特征。

E-022A 只回答一个问题：

> 在 DINO K256 候选集中，哪些 no-GT 特征能够区分正确候选与 hard negatives？

## 2. 输入

- Frozen DINOv2-L full4096 K256 candidates。
- DINO checkpoint SHA：`d5383ea8f4877b2472eb973e0fd72d557c7da5d3611bd527ceeb1d7162cbf428`。
- 官方 train/dev split：train `1607`，dev `404`。
- 原始 `512x512` optical/SAR；stride-8 `64x64=4096`。
- `truth_flow` 只用于 train labels/reward 和 dev metric/evaluation；dev inference 阶段不得读取。

## 3. 不做什么

- 不宣称最终 sparse affine feedback 成功。
- 不启动 E-022B、rescue、OS424/confirm 或完整 sparse feedback。
- 不微调或改写 DINO/GDROS/baseline checkpoint。
- 不修改 E-015A~E-021A 历史产物。
- 不用 RANSAC、三点、131k hypothesis enumeration。
- 不新增 hidden full `4096x4096` cross-image tensor；DINO K256 candidate generation 是冻结输入。

## 4. 特征族

所有特征必须在 truth_flow label join 前物化，保存 feature manifest、SHA、trace。

### F0：baseline rank/margin

- DINO score、rank、同 source score margin、entropy；
- target duplicate/collision；
- pair/source-wise score normalization。

### F1：raw/log-SAR patch evidence

- optical raw patch、SAR raw/log-SAR patch；
- multi-scale patch statistics；
- NCC/ZNCC、rank/census、gradient orientation/magnitude、edge map。

### F2：DINO local patch evidence

- source/target DINO local crop；
- candidate endpoint neighborhood pooling；
- source内 rank/margin normalization。

### F3：learned patch verifier

- 小型 Siamese / cross-attention / CNN verifier；
- 输入 raw/log-SAR、gradient/census/structure、DINO local patch；
- 使用 same-source hard negatives 和 listwise/source-choice loss；
- 输出 candidate score；不直接输出最终 affine。

### F4：neighborhood consistency

- source kNN 邻域内候选 displacement consistency；
- local affine consistency proxy；
- region-neighbor support；
- target collision penalty。

禁止把 F4 做成 RANSAC、三点或 131k hypothesis enumeration。

### F5：region/context evidence

- source/target region structure summary；
- region-level optical/SAR context compatibility；
- pair-adaptive z-score / rank normalization。

### F6：fusion tracks

- shallow linear / MLP fusion；
- listwise source-competition transformer；
- geometry-aware fusion score。

## 5. 标签与训练

- endpoint labels：candidate target endpoint 与 raw truth_flow endpoint 的 2/5/8px 距离。
- source-choice labels：每个 source 内最接近 truth_flow 的 candidate，允许 dustbin。
- labels 只用于 train loss 和 dev metric，不得参与 dev inference。
- learned tracks 使用 train-only threshold/budget calibration。
- dev404 只能使用冻结 checkpoint 和 train-calibrated parameters。

## 6. 指标

候选级：

- endpoint@2/5/8 AP/AUROC；
- score distribution、positive/negative margin。

source级：

- hit@1 / hit@4 / hit@8；
- MRR；
- best-correct-vs-best-wrong margin；
- recoverable source coverage。

selected-set级：

- selected precision@2/5/8；
- correct@2 mean/P10/P50/P90；
- enrichment ratio；
- selected count；
- source region/quadrant coverage；
- ordinary LS selected-set AEPE/CMR/PLR。

对照：

- candidate pool base；
- DINO score/rank；
- random；
- region quota；
- E-020B top tracks；
- E-021A expected_top256 reference。

## 7. Gate

### P0：实现与隔离

必须 PASS：

- frozen SHA、split、DINO checkpoint、K256 parity；
- no baseline writes；
- no OS424/confirm/datum；
- no DINO/GDROS finetune；
- feature materialization before truth_flow label join；
- coordinate direction、stride-8、patch sampling tests；
- no RANSAC/no 131k/no hidden new full `4096x4096`；
- feature manifest SHA/trace 完整。

P0 fail：`FEATURE_IMPLEMENTATION_BLOCKED`。

### G0：train-full feature learnability

在 1607 train pairs 上训练/校准 learned tracks，并执行 no-GT train inference。

至少一个 learned/fusion track 需要达到：

- selected precision@2 >= `2%`；
- correct@2 mean >= `4`；
- P50 correct@2 >= `2`；
- enrichment@2 >= `10x` candidate pool base；
- source regions mean >= `32` 或 quadrant coverage mean >= `3.5`。

若全不过：`NO_TRAIN_FEATURE_SEPARABILITY`，不跑 dev404。

### G1：dev404 feature discriminability

G0 通过后运行 dev404，用 train-calibrated thresholds/budgets。

判读：

- `NO_FEATURE_FOUND`：无 track 明显超过 DINO/E-021A reference；
- `WEAK_FEATURE_FOUND`：dev selected precision/correct count 明显超过 reference，但未达可用阈值；
- `USABLE_FEATURE_FOUND`：precision@2 >= `3%`，correct@2 mean >= `8`，P50 correct@2 >= `4`，且 coverage 通过；
- `FEATURE_FOUND_AFFINE_FAIL`：selected set 富集足够但 AEPE > `25 px`；
- `STRONG_FEATURE_FOUND`：selected-set AEPE <= `25 px` 或相对 E-021A/E-020B reference 改善 >= `25%`。
