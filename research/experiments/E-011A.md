# E-011A：Raw-image Cross-modal Patch Descriptor Retriever

## 目的

E-011A 检验：

> 不再使用 E-008A cached raw/structure/local tail，而是直接从 512x512 optical/SAR 原图提取多尺度
> patch descriptor，能否在 S1 matched-region union 内显著超过 frozen S2 top64？

本实验不修改 GDROS baseline，不启动完整 sparse affine feedback。

## Baseline 污染隔离

GDROS baseline 只读。E-011A 必须使用独立路径：

- 新代码：`experiments/sparsegeo/e011a/`
- 新 cache：`runs/E-011A/run-*/cache-*`
- 新 checkpoint：`runs/E-011A/run-*/models`
- 新结果：`runs/E-011A/run-*` 与 `research/results/E-011A/`

禁止：

- 修改 GDROS baseline 源码、checkpoint、配置、evaluation protocol；
- 写入/覆盖 E-000、E-001、E-006A、E-008A、E-009A、E-010A 的 run/cache/result；
- 训练或微调 GDROS backbone / FeatureTransformer；
- 把 E-011A 权重作为 GDROS fallback；
- 为了通过 gate 改 baseline evaluator 语义。

必须在 `RUN_MANIFEST.json` 记录 baseline read-only paths 与 E-011A write paths，并由 reviewer 审计。

## 固定输入

- 数据：official training archive 原始 `512x512` optical/SAR，train/dev split 沿用 group-isolated
  `1607/404`。
- S0/S1：复用 E-008A source proposals 与 matched-region union，只用于限定搜索区域。
- raw `truth_flow`：唯一 train/eval 标签。
- 禁止：datum、OS424、confirm。

## 新模块

训练 `RawImagePatchDescriptorRetriever`：

- 输入：原始 optical/SAR 图像 patch，可含多尺度上下文，例如 `16/32/64` patch 或等价 pyramid。
- 结构：modality-specific optical/SAR stems + shared descriptor projection；输出 stride-8 descriptor。
- 检索：每个 source proposal 只对 S1 matched-region union 内 target tokens 打分，输出 topR。
- 禁止使用 GDROS frozen features、frozen cosine、region score 作为 learned input 或 teacher。
- 禁止使用 E-008A cached raw/structure/local tail 作为主 descriptor 输入；可只用于 S0/S1 identity/parity。

## 训练目标

- 主 loss：full-union listwise retrieval 或 supervised contrastive retrieval。
- 正样本：target pixel 到 raw endpoint `<=2 px`；无 2px positive 时可用 nearest-token Gaussian soft target。
- Hard negatives：当前模型高分且离 GT 远的 S1 union tokens。
- 必须报告 soft label 公式、negative mining 规则、proposal sampling 规则。
- 必须验证 gradient 到 patch encoder/projection，toy subset 能过拟合。

## 对照

必须复现并报告：

- frozen S2 top64：mean `50.015`，P10/P50/P90 `26/48/78`，base2px `0.05161%`，
  nearest P50/P90 `15.490/75.309 px`。
- E-010A cached-evidence strong top64：mean `37.077`，P10/P50/P90 `16/36/60`，base2px `0.03826%`。
- E-006A candidate baseline：mean `66.210`，P10/P50/P90 `33/64/98`，oracle AEPE `0.190768 px`，
  PairLocalReady/valid `100%/100%`。

## Gate

### G0：实现、隔离和协议

- Baseline isolation PASS：GDROS baseline paths read-only，E-011A outputs 独立。
- S0/S1 trace parity PASS。
- frozen S2、E-010A、E-006A baseline parity PASS。
- learned score 在 top64 前使用。
- topR outputs 在 label join 前物化。
- 不使用 GDROS frozen feature input、frozen score teacher、E-008A cached tail main input。
- 无 OS424/confirm/datum label、hidden `4096x4096`、full-image blind search、dense flow/GRU、fallback。
- 自动测试 PASS，至少一名 reviewer APPROVE。

### G1：显著超过 frozen S2

top64 必须同时满足：

- mean 2px-correct proposals `>=60.0`
- P10 `>=31`
- P50 `>=56`
- base2px `>=0.0619%`
- nearest P50 `<15.490 px`
- nearest P90 `<75.309 px`

若 G1 FAIL，状态为 `COMPLETED / RAW_PATCH_RETRIEVER_FAIL`，停止。

### G2：候选生成资格

仅 G1 PASS 后判读：

- mean 2px-correct proposals `>66.210`
- P10 `>33`
- P50 `>64`
- oracle affine AEPE `<=0.5 px`
- PairLocalReady/valid `>=99%`

若 G2 FAIL，状态为 `COMPLETED / RAW_PATCH_IMPROVED_NOT_QUALIFIED`，停止。

### G3：topR 诊断

报告 R=`4/8/16/32/64/128` 的 mean/P10/P50/P90、base rate、nearest distance、oracle affine。
top128 不得在 top64 G1/G2 失败时追认为成功。
