# E-023A：Sparse Affine-State Recurrent Matcher

方法版本：`M001 v2.7 prototype`

状态：`USER_APPROVED / READY_FOR_ENGINEERING`

## 1. 问题重定义

E-020B/E-021A/E-022A 已证明：在 frozen DINO K256 候选池里后验挑真点，不足以形成可用点集。即使
learned/fusion verifier 可把正确点富集到约 `30x` candidate-pool base，precision@2 仍只有约 `1.3%`，
correct@2 mean 约 `1.8`，AEPE 约 `34 px`。

因此 E-023A 不再做 fixed-candidate selector。它验证新的主线：

> 用低维 affine/region state 递归产生 state-conditioned local matches，再用这些观测更新 affine state。

这是一版有效性原型，允许较高耗时；若有效，再另行批准 E-023B 做加速。

## 4. 方法

### 4.1 Coarse affine/region state initialization

必须从图像本身产生初始 state：

- 低分辨率 region/grid 表征，例如 `8x8` 或 `16x16`；
- 允许 low-res region cross-attention/correlation；
- 输出 `B<=16` 个 affine/region state hypotheses；
- 初始 state 必须有 no-GT trace；
- 可为 learned state head 或 deterministic low-res region matching。

### 4.2 State-conditioned local matching

每轮 `t=1..T`：

- `T=2` 或 `T=3`；
- source anchors 半稠密、region-balanced，建议 `S=512~2048`；
- 当前 affine state 将 source anchors warp 到 target；
- 只在 target 预测位置附近搜索 local window，例如 `9x9 -> 7x7 -> 5x5` token window；
- local matcher 可用 raw/log-SAR、gradient/census/structure、DINO local crop、轻量 cross-attention；
- 输出 local target distribution、confidence/dustbin、residual；
- 记录每轮 window 是否覆盖 GT endpoint。

### 4.3 Recurrent affine-state update

- 每个 basin 维护 affine matrix、confidence、coverage、residual summary；
- 根据 local observations 做 weighted affine update 或等价 differentiable update；
- 可有 learned damping/residual correction；
- 更新后的 state 必须改变下一轮 local search center；
- 记录每轮 state matrix、delta、coverage、grid AEPE、CMR。

### 4.4 Loss

训练仅用 train truth_flow：

- local window CE / soft endpoint loss；
- GT endpoint out-of-window penalty；
- affine/grid loss；
- recurrent improvement loss；
- confidence/dustbin loss；
- coverage/diversity regularization；
- multi-basin oracle-min 或 soft assignment loss。

该监督不是 teacher distillation。
