# E-020A：High-Capacity Candidate Verifier Learnability Diagnostic

## 目的

E-020A 回答：

> 在 DINO-K256 候选池中，给网络足够强的跨模态 patch 观测、候选竞争和几何消息传递后，是否能学习
> 预测一部分高置信 GT 正确候选？

本实验不是最终低成本方法，也不是 teacher distillation。训练标签来自 raw truth_flow；dev 推理禁止读取
GT。目标是判断“候选/输入是否可学习地区分”，并区分 train 不可过拟合、train-only memorization、
candidate 可分但 affine 失败等不同情况。

## 输入与隔离

- frozen DINOv2-L full4096 K256 candidates；
- DINO checkpoint SHA：
  `d5383ea8f4877b2472eb973e0fd72d557c7da5d3611bd527ceeb1d7162cbf428`；
- official training split：train `1607` / dev `404`；
- 原始 optical/SAR `512x512` 图像；
- raw truth_flow 仅用于 train labels、dev metrics 和 oracle diagnostics；
- 禁止 OS424/confirm/datum；
- 禁止修改 DINO/GDROS checkpoint、baseline source、E-015A/E-016A/E-017A/E-018A/E-019A artifacts。

## 强网络结构绑定

若以下任一主通道未实现，负面结果不得解释为“输入不可分”，状态应为
`IMPLEMENTATION_BLOCKED_OR_MODEL_TOO_WEAK`。

### Candidate token

每个 source-target candidate 至少包含：

- source xy、target xy、displacement；
- DINO score、rank、gap、z-score；
- source/target region id；
- collision、boundary、coverage proxy；
- 可选 E-019A local/regional/global geometry proxy。

### Patch evidence

- optical source patch 与 SAR target patch；
- 多尺度 patch 至少两档，例如小窗和大窗；
- modality-specific raw/structure stems；
- DINO local feature crop 或 bilinear sampled feature；
- patch output 必须进入 candidate token，并有 nonzero/gradient 检查。

### Candidate competition and graph

- within-source K256 attention、listwise normalization 或等价候选竞争；
- explicit dustbin/abstention；
- source-neighbor / same-region / adjacent-region graph message passing；
- displacement/residual 必须进入 graph edge 或 attention bias；
- global/affine basin tokens `B>=8`，且必须反向调制 candidate confidence/residual。

### Heads

- endpoint correctness：`<=2px` 主，`<=5px` 辅；
- per-source candidate/dustbin；
- basin assignment/residual；
- confidence calibration；
- selected-set affine diagnostic path：weighted LS 或等价可审计路径。

建议总参数量 `>=2M`；若因资源低于该量，需 reviewer 确认仍满足“强网络”语义，否则结果只能判
model-too-weak。

## 训练

训练只使用 train split truth_flow：

- endpoint hard labels：`<=1/2/5 px`；
- soft endpoint score；
- per-source positive/dustbin；
- pairwise/listwise ranking；
- focal/class-balanced BCE 或 asymmetric loss；
- hard negative mining；
- basin consistency/residual loss；
- affine/grid loss；
- coverage/diversity loss。

训练必须记录每个 loss component、正负样本比例、hard negative 来源、gradient reachability 和 strict
checkpoint load。

## 评估

所有 dev tracks 均为 no-GT inference。

固定 tracks：

- topM：`M=32/64/128/256`；
- region quota：`8x8` source regions，quota=`1/2/4`；
- train-calibrated threshold：只用 train 定阈值；
- dynamic confidence/dustbin：模型直接输出 active set。

每个 track 报告：

- endpoint@2 AP/AUROC；
- correct@2 count mean/P10/P50/P90；
- precision@2 mean/P10/P50/P90；
- active count、coverage、quadrant coverage；
- selected-set affine AEPE、CMR@1/2/5、PLR；
- selected source distribution、collision、condition proxy；
- failure buckets。

同时报告：

- train-small overfit；
- train-full；
- dev404；
- dev sweeps 只作诊断，不能用于主 gate 追认。

## Gates

### P0：隔离与输入

未通过则 `IMPLEMENTATION_BLOCKED`。

- frozen SHA 与 split `1607/404` PASS；
- DINO checkpoint SHA PASS；
- K256 parity with E-016A/E-019A PASS；
- candidate/features before truth_flow label join PASS；
- no OS424/confirm/datum PASS；
- no baseline writes PASS；
- coordinate direction optical source -> SAR target PASS；
- stride-8 / patch sampling / DINO feature sampling PASS；
- no RANSAC/三点/131k PASS；
- no hidden new full `4096x4096` cross-image tensor beyond frozen candidate generation PASS。

### G0：强网络与训练链路

未通过则 `IMPLEMENTATION_BLOCKED_OR_MODEL_TOO_WEAK`。

- patch encoder、within-source competition、source-neighbor graph、global/affine tokens、heads 均被调用；
- gradients 到达所有 required modules；
- loss finite/nonzero；
- hard negative mining 生效；
- strict checkpoint load；
- candidate order permutation sanity PASS；
- toy geometry / selected affine sanity PASS；
- train-small overfit 完成，并至少满足：
  - endpoint@2 AP >= `0.05`；
  - region_quota128 correct@2 mean >= `16` 或 top128 correct@2 mean >= `16`；
  - selected-set affine AEPE <= `14.8 px`，即至少比 E-018A final `29.580 px` 改善 50%。

若 train-small overfit 未达到这些阈值，必须先排查实现/标签/采样；reviewer 未确认前不得解释为方法失败。

### G1：dev learnability

对照：

- E-019A best proxy：correct@2 mean `0.649`、P50 `0`、precision `0.5067%`、PLR `9.41%`；
- E-017A K256：AEPE `45.906`、correct@2 mean `1.047`、precision `0.0070`；
- E-018A final：AEPE `29.580`、CMR@2 `1.96%`、PLR `28.96%`。

判读阈值：

- `INPUT_NOT_LEARNABLE_TRAIN_FAIL`：P0/G0 reviewer 通过后，train-small 与 train-full 都不能形成
  高纯前缀或 affine 改善。
- `TRAIN_MEMORIZATION_ONLY_DEV_FAIL`：G0 train overfit 通过，但 dev 所有预注册 tracks 均未达到
  `USEFUL`。
- `LEARNABLE_SIGNAL_FOUND_AFFINE_FAIL`：dev 至少一个预注册 track 达到：
  - endpoint@2 AP >= `0.02`，或
  - correct@2 mean >= `16` 且 precision >= `5%`，
  但 selected-set affine AEPE 仍 > `14.8 px` 或 PLR <= `50%`。
- `USEFUL_LEARNABLE_SIGNAL_FOUND`：dev 至少一个预注册 track 同时达到：
  - correct@2 mean >= `16`；
  - P50 correct@2 >= `8`；
  - precision@2 >= `5%`；
  - PLR > `50%`；
  - selected-set affine AEPE <= `14.8 px`。
- `STRONG_LEARNABLE_SIGNAL_FOUND`：dev 至少一个预注册 track 同时达到：
  - correct@2 mean >= `48`；
  - P50 correct@2 >= `32`；
  - precision@2 >= `15%`；
  - PLR >= `85%`；
  - selected-set affine AEPE <= `3.0 px`；
  - CMR@2 >= `50%`。

若多项成立，主判读优先级：

`IMPLEMENTATION_BLOCKED > IMPLEMENTATION_BLOCKED_OR_MODEL_TOO_WEAK > STRONG_LEARNABLE_SIGNAL_FOUND > USEFUL_LEARNABLE_SIGNAL_FOUND > LEARNABLE_SIGNAL_FOUND_AFFINE_FAIL > TRAIN_MEMORIZATION_ONLY_DEV_FAIL > INPUT_NOT_LEARNABLE_TRAIN_FAIL`。

## Ablations

必须至少报告：

- geometry token only / no patch；
- patch only / no graph / no global tokens；
- patch + within-source competition；
- patch + competition + source-neighbor graph；
- full model + global/affine tokens；
- full model without DINO local features；
- full model without raw patches；
- full model without E-019A geometry proxy features。

## Review

两路 reviewer：

1. model/training/architecture reviewer：检查强网络通道、训练链路、梯度、loss、overfit 是否真实；
2. evaluator/protocol/leakage reviewer：检查 split、GT 隔离、dev threshold、baseline write audit、metrics。

任一 blocking finding，则不得解释负面结果。
