# E-028B：Drift-Controlled Dual-Adapter Tuning Sweep

方法版本：`M001 v3.3 prototype`

状态：`USER_APPROVED / READY_FOR_ENGINEERING`

## 1. 目标

E-028B 继续双 adapter 路线，但把 E-028A 暴露的问题纳入设计：optical adapter 不能自由漂移。目标是在
`optical drift <= 0.02` 的安全边界内，通过受控 tuning sweep 判断 dual-adapter 是否能超过 E-027A 单 SAR
adapter，以及最大能提升到什么程度。

核心问题：

> 在同一个 E-025A fair matcher/NMS/affine evaluator 下，受 drift 约束的双 adapter 是否能安全超过
> E-027A 的 `26.246 / 0.569 / 0.438`？

本实验只证明 feature frontend gain；不宣称完整 sparse affine recurrent matcher 成功。

## 2. 已知对照

- `E027A_FROZEN_DINO_OPTICAL__SAR_ADAPTER`：AEPE `26.246`，recall@2 `0.569`，correct@2 `0.438`；
- E-028A blocked：optical drift `0.178630 > 0.020000`；train sanity AEPE `16.8356`，
  recall@2/correct@2 `1.0440/0.7188`，只能说明 unsafe upper signal；
- `GDROS_FEATURE_FAIR`：AEPE `96.430`，recall@2 `0.729`，correct@2 `0.762`；
- E-025A primary fair matcher：`topK256_nms2_quota4_mutual0`。

## 3. 数据与边界

- train/dev split：train `1607`，dev `404`。
- 从 train `1607` 内确定性划分 `train_fit` 与 `train_calib`，规则写入 manifest。
- `train_fit` 用于训练候选配置；`train_calib` 用于选 primary 配置。
- dev `404` 只用于正式 G1，一律不得参与调参、阈值、early-stop 或配置选择。
- 原始 optical/SAR 固定 `512x512`；`truth_flow` 只用于 train loss、label 和 metrics。
- `datum`、OS424/confirm 禁止参与。
- 原始 DINOv2/GDROS checkpoint 与 baseline cache 只读。

## 4. Tuning sweep

候选配置数量建议 `<=12`。必须至少覆盖：

- E-027A parity；
- projection-only optical adapter；
- small residual optical adapter；
- small residual + modality-invariant losses。

推荐 sweep 维度：

- optical adapter residual scale / gate：`0.0`, `0.01`, `0.03` 或等价；
- teacher consistency weight：low/medium/high；
- optical trainable subset：projection-only、adapter+LayerNorm/bias、optional low-rank LoRA；
- modality-invariant loss：off/medium；
- local-structure consistency：on/off。

资源不足时，优先保留最小 4-track sweep。允许多卡并行训练/评估候选配置，但必须保持同一 frozen baseline 与同一 matcher。

## 5. Loss 与约束

继承 E-028A，强化 drift control：

- optical teacher consistency；
- bounded residual adapter 或 adapter output norm penalty；
- paired-token contrastive / sampled-softmax；
- modality-invariant alignment；
- variance/covariance anti-collapse；
- local-neighborhood structure consistency；
- cycle / mutual consistency；
- soft affine/grid loss；
- SAR augmentation consistency。

domain-adversarial / modality-confusion 可作为 optional；若不稳定，允许关闭并报告。

## 6. Primary selection

Primary 配置只能由 `train_calib` 选择：

1. 必须满足 optical drift `<=0.02`；
2. 在 `train_calib` 上相对 E-027A parity，AEPE 改善 `>=5%` 或 recall/correct 改善 `>=10%`；
3. 若多个配置通过，按 `AEPE priority -> recall/correct -> lower drift -> lower resource` 选；
4. 若无 safe 配置通过，G0 停止，不运行 formal dev。

drift `>0.02` 的配置只可记录为 unsafe diagnostic，不支持成功 claim。

## 7. 评价

正式 dev 比较：

```text

-> materialize descriptors before truth_flow join
-> E-025A primary fair matcher topK256_nms2_quota4_mutual0
-> same affine evaluator
-> compare with E-027A, GDROS_FEATURE_FAIR, DINO_FOUNDATION_FAIR
```

必须报告：

- tuning_grid、train_fit/train_calib split、selection_report；
- optical drift train_calib/dev；
- endpoint recall@1/2/5；
- selected correct@2 mean/P50；
- fair affine AEPE；
- CMR@2 / CMR@5 / PLR；
- region/quadrant coverage；
- train_calib vs dev gap；
- resource p50/p95/max、peak memory、frozen/trainable parameter counts。

## 8. Gate

### P0：implementation and tuning isolation

必须 PASS：

- E-027A parity baseline present；
- E-028A blocked result and drift cause recorded；
- deterministic train_fit/train_calib split recorded；
- no dev config/threshold/early-stop selection；
- DINOv2/GDROS original checkpoint readonly；
- optical and SAR adapters called and trainable；
- primary is dual-adapter, not SAR-only or scratch-only；
- no baseline writes；
- no OS424/confirm/datum；
- feature materialized before truth_flow join；
- E-025A primary matcher config reused。

P0 fail：`DRIFT_CONTROLLED_TUNING_IMPLEMENTATION_BLOCKED`。

### G0：train-calibration selection

必须 PASS：

- candidate trainings finite；
- selected primary losses active；
- gradients 到达 optical 与 SAR adapters；
- frozen DINO modules 保持 frozen；
- selected primary optical drift `<=0.02`；
- selected primary 在 train_calib 上超过 E-027A parity；
- strict checkpoint load；
- train_calib no-GT hard matcher finite；
- reviewer 对 tuning isolation approve。

G0 fail：`NO_SAFE_DUAL_ADAPTER_CONFIG` 或 `DUAL_ADAPTER_TUNING_BLOCKED`。

### G1：formal dev comparison

判读：

- `NO_SAFE_DUAL_ADAPTER_DEV_GAIN`：safe primary 未超过 E-027A；
- `SAFE_DUAL_ADAPTER_GAIN_FOUND`：相对 E-027A AEPE 改善 `>=5%` 且 recall/correct 不下降，或 recall/correct
  改善 `>=10%` 且 AEPE 不差超过 `5%`；
- `SAFE_DUAL_ADAPTER_STRONG_GAIN`：AEPE 改善 `>=10%` 且 recall/correct 同时优于 E-027A；
- `GDROS_RECALL_BRIDGE_FOUND`：recall@2 或 correct@2 达到 GDROS feature-only 的 `>=75%`，且 AEPE 明显优于 GDROS；
- `DUAL_ADAPTER_UNSAFE_ONLY`：只有 drift `>0.02` diagnostic tracks 有增益，不能作为成功。
