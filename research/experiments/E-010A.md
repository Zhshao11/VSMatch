# E-010A：Strong Cross-modal Region-local Retriever

## 目的

E-010A 不是 E-009A rescue。它检验一个更强命题：

> 在固定 E-008A source proposals 与 matched-region union 的条件下，用强跨模态 patch/descriptor
> 表示、full-union/listwise retrieval 和 hard negative mining，能否显著超过 frozen S2 top64，并接近
> 或超过 E-006A candidate baseline？

Frozen S2 是最低对照，不是 teacher 或目标上限。

## 固定输入

- 复用 E-008A 的 train/dev split、source proposals、4/8/16 region matching 和 matched-region union。
- S0/S1 trace 必须与 E-008A-STAGE-DIAG parity。
- 不改变 region top-L，不做 full-image blind search，不构造 hidden `4096x4096`。
- raw `truth_flow` 是唯一训练/eval 标签；datum、OS424、confirm 禁用。

## 新模块

训练 `StrongRegionLocalRetriever`：

- 输入：原始 `512x512` optical/SAR，可加入结构通道：梯度、边缘、局部方差、SAR log/intensity
  normalization。
- 禁止输入：GDROS frozen features、frozen cosine score、region score 作为 learned input 或 teacher。
- 结构建议：
  - modality-specific stem；
  - shared 或 lightly-coupled patch encoder；
  - stride-8 dense descriptor head；
  - optional local patch token aggregation；
  - descriptor dimension 和参数量需报告，参数量不强行限制为小模型。
- 检索：每个 source proposal 只对其 S1 matched-region union 内全部 target tokens 打分，输出 topR。

## 训练目标

必须区别于 E-009A sampled CE：

- 主 loss：full-union/listwise retrieval loss，对 union 内全部 target token 或等价完整 mask 归一化；
- 正样本：target pixel 到 raw endpoint `<=2 px`，若无 2px positive 可用 nearest-token soft target；
- soft label：可用 Gaussian distance target，但公式必须写入 `RESULT_CARD.md`；
- hard negative mining：从当前模型高分但距离 GT 远的 in-union targets 中采样或加权；
- dustbin/in-bounds 辅助 loss 可选，但不能替代 retrieval loss；
- 必须验证 gradient 到达 encoder/projection，toy subset 可过拟合。

## 对照

必须复现并报告：

- frozen S2 top64：mean `50.015`，P10/P50/P90 `26/48/78`，base2px `0.05161%`，
  nearest P50/P90 `15.490/75.309 px`。
- E-009A learned top64：mean `34.745`，P10/P50/P90 `15/33/55.7`，base2px `0.03585%`。
- E-006A candidate baseline：mean `66.210`，P10/P50/P90 `33/64/98`，oracle AEPE `0.190768 px`，
  PairLocalReady/valid `100%/100%`。

## Gate

### G0：实现与协议

- S0/S1 trace parity PASS。
- frozen S2 与 E-009A baseline parity PASS。
- learned score 在 top64 前使用。
- topR outputs 在 label join 前物化。
- 无 GDROS frozen feature input、无 frozen score distillation、无 OS424/confirm/datum label。
- 无 hidden `4096x4096`、full-image blind search、dense flow/GRU、baseline fallback。
- 自动测试 PASS，至少一名 reviewer APPROVE。

### G1：显著超过 frozen S2

strong top64 必须同时满足：

- mean 2px-correct proposals `>=60.0`
- P10 `>=31`
- P50 `>=56`
- 2px candidate base rate `>=0.0619%`
- nearest P50 `<15.490 px`
- nearest P90 `<75.309 px`

若 G1 FAIL，状态为 `COMPLETED / STRONG_RETRIEVER_FAIL`，停止。

### G2：候选生成资格

仅 G1 PASS 后判读。strong top64 必须满足：

- mean 2px-correct proposals `>66.210`
- P10 `>33`
- P50 `>64`
- oracle affine AEPE `<=0.5 px`
- PairLocalReady/valid `>=99%`

若 G2 FAIL，状态为 `COMPLETED / RETRIEVER_IMPROVED_NOT_QUALIFIED`，停止。

### G3：topR 诊断

报告 R=`4/8/16/32/64/128` 曲线：mean/P10/P50/P90、base rate、nearest distance、oracle affine。
top128 不得在 top64 G1/G2 失败时追认为成功，只能作为下一轮用户决策证据。

## 资源

报告：

- 参数量、训练时间、GPU、峰值显存；
- eval p50/p95、最大 union tokens、最大 live score elements；
- 与 E-009A eval p50/p95 `244.33/292.81 ms` 对比；
- 若模型明显更重，说明候选质量增益是否足以支持后续轻量化。
