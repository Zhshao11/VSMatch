# E-026A：DINOv2-Inspired Opt-SAR Adaptive Feature Network

方法版本：`M001 v3.0 prototype`

状态：`USER_APPROVED / READY_FOR_ENGINEERING`

## 1. 目标

E-026A 的目标是训练一个我们自己的 optical-SAR adaptive feature network。它参考 DINOv2 的 patch-token
ViT、全局上下文和 teacher/distillation 训练思想，但必须实际读取 optical 与 SAR 输入，并显式适配 SAR。

核心问题：

> 在同一个 E-025A fair matcher/NMS/affine evaluator 下，新训练的 opt-SAR DINO-style feature 是否比
> frozen DINO feature 和 GDROS feature-only baseline 更强？

本实验只证明 feature frontend 是否有增益；不宣称完整 sparse affine recurrent matcher 成功。

## 2. 已知对照

E-025A primary fair matcher：`topK256_nms2_quota4_mutual0`。

对照指标：

- `GDROS_FEATURE_FAIR`：AEPE `96.430`，recall@2 `0.729`，correct@2 `0.762`；
- `DINO_FOUNDATION_FAIR`：AEPE `79.246`，recall@2 `0.198`，correct@2 `0.163`；
- 完整 GDROS system 只能作为 secondary reference，不参与 primary feature baseline。

## 3. 数据与边界

- train/dev split：train `1607`，dev `404`。
- 原始 optical/SAR 固定 `512x512`。
- `truth_flow` 只用于 train loss、label 和 metrics。
- `datum` 仅做 archive 完整性/SHA，不作为标签。
- OS424/confirm 禁止参与。
- GDROS baseline、DINOv2 checkpoint、历史 feature/cache/run 目录只读。
- 若使用 DINOv2 权重，必须记录 SHA；只能作为 frozen teacher、初始化副本或 reference，不得修改原 checkpoint。

## 4. 网络结构

必须实现一个独立训练的 `OPT_SAR_DINOSTYLE_NET`：

```text
optical RGB 512x512
  -> optical patch stem
  -> optical modality adapter

SAR 512x512
  -> log/normalized SAR + structure/speckle-robust channels
  -> SAR adaptive patch stem
  -> SAR modality adapter

both streams
  -> shared or tied ViT-style patch-token encoder
  -> optional global/register tokens
  -> descriptor projection + L2 normalization
  -> optical/SAR dense token descriptors
```

绑定：

- primary scale 优先继承 E-025A `1/16`；若实现 `1/8`，只能作为 secondary/diagnostic，不能后验替换 primary。
- SAR adapter 至少包含 log-intensity normalization 与一种 local structure / gradient / local-energy 通道或等价 learnable stem。
- 输出 descriptor 必须能进入 E-025A unified fair matcher。
- 允许 DINOv2-style EMA teacher 或 frozen DINO optical teacher alignment，但要在 manifest 中区分。

## 5. Loss

必须包含：

- optical→SAR token correspondence loss；
- SAR→optical token correspondence loss；
- hard-negative contrastive / listwise retrieval loss；
- cycle 或 mutual consistency loss；
- differentiable soft affine/grid loss；
- SAR augmentation loss path：speckle/noise/intensity/log-scale perturbation 后 descriptor 仍可匹配；
- descriptor normalization regularization。

允许：

- frozen DINOv2 optical teacher feature alignment；
- EMA/self-distillation；
- train-only GDROS teacher 辅助项。

禁止把 teacher 输出写成 GT；必须分别报告 GT-supervised、DINO-teacher、GDROS-teacher loss。

## 6. 评价

正式 dev 比较：

```text
feature extractor
-> materialize descriptors before truth_flow join
-> E-025A primary fair matcher topK256_nms2_quota4_mutual0
-> same affine evaluator
-> compare with GDROS_FEATURE_FAIR and DINO_FOUNDATION_FAIR
```

必须报告：

- endpoint recall@1/2/5；
- GT endpoint rank / topK recall；
- selected count；
- selected correct@2 mean/P50；
- fair affine AEPE；
- CMR@2 / CMR@5；
- PLR；
- target collision；
- region/quadrant coverage；
- train/dev gap；
- resource p50/p95/max 和 peak memory。

## 7. Gate

### P0：implementation and isolation

必须 PASS：

- optical 与 SAR 输入均被实际使用；
- SAR adapter/通道存在并被调用；
- DINO/GDROS/baseline checkpoint 只读；
- no baseline writes；
- no OS424/confirm/datum；
- train/dev split isolation；
- feature materialized before truth_flow join；
- primary matcher config 与 E-025A 一致；
- no dev matcher/threshold selection；
- source/checkpoint/config SHA 完整。

P0 fail：`OPT_SAR_DINOSTYLE_IMPLEMENTATION_BLOCKED`。

### G0：training sanity

必须 PASS：

- train loss finite 且主要 loss 非零；
- gradients 到达 optical stem、SAR stem/adapter、ViT encoder、descriptor projection；
- strict checkpoint load；
- train no-GT hard matcher inference finite；
- train retrieval 或 fair affine utility 相对初始化/随机有改善；
- reviewer 对训练链路与隔离边界 approve。

G0 fail：`OPT_SAR_FEATURE_TRAINING_BLOCKED`。

### G1：dev feature comparison

判读：

- `NO_OPT_SAR_FEATURE_GAIN`：新网络没有在 AEPE、recall@2 或 correct@2 的任一核心维度形成有效增益；
- `SAR_ADAPTIVE_FEATURE_GAIN_FOUND`：相对 `DINO_FOUNDATION_FAIR` AEPE 改善 `>=10%`，且 recall/correct 不低于 DINO；
- `GDROS_FEATURE_RECALL_GAIN_FOUND`：相对 `GDROS_FEATURE_FAIR` recall@2 或 correct@2 改善 `>=10%`，且 AEPE 不差于 GDROS；
- `OPT_SAR_FRONTEND_STRONG_GAIN`：AEPE 改善 `>=25%`，且 recall/correct 同时优于两个 feature-only baseline；
- `READY_FOR_SPARSE_FEEDBACK_FRONTEND`：feature 指标达到可作为下一版 R0/coarse/local observation 输入的预注册阈值。
