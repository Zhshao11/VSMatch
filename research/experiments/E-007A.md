# E-007A 实验单：Patch / Structure / Descriptor 观测证据诊断

方法：`M001 v1.0 / Observation-Evidence Sparse Affine Feedback`

状态：`USER_APPROVED / FROZEN_FOR_ENGINEERING`

## 1. 目的

验证用户批准的三个更强观测方向是否能改善 E-006A 候选的无 GT 可选择性：

- Patch evidence：候选点周围局部窗口匹配。
- Structure evidence：跨模态稳健结构通道。
- Descriptor evidence：训练轻量跨模态局部描述子。

本实验不继续调 E-006A 的 26 维几何 selector。核心问题是：加入更强局部观测后，能否把
E-006A-SELECT-DIAG 的 main D2 dev topK-32 precision `2.259%`、affine AEPE `63.516 px` 显著改善。

## 2. 冻结输入与禁止项

- 复用 official training archive 的 group-isolated `1607/404` train/dev。
- 输入固定原始 `512x512`；raw truth_flow 是训练标签和指标的唯一权威。
- 默认复用 E-006A corrected candidate generator、M256 proposals 和候选 trace；第一版不扩大 source
  proposal grid。
- OS424、external confirm、datum 标签、旧 invalid `p0-gate.json` 禁止访问。
- 不训练 GDROS backbone、FeatureTransformer 或原 checkpoint。
- 不使用 dense flow hidden state、dense GRU、`4096x4096` cross-image tensor、RANSAC、IRLS、
  三点 hypothesis enumeration 或 baseline fallback。

## 3. 观测证据

所有特征必须在 label join 前 materialize，并通过 no-GT audit。

### P：Patch Evidence

- 对每个 candidate 抽取 source optical patch 与 target SAR patch。
- patch 尺度：raw image `33x33`、`65x65`；GDROS stride-8 feature patch `5x5`、`9x9`。
- SAR raw preprocessing 固定为 `log1p(abs(x))` 后按图像 robust median/IQR normalization。
- optical raw 固定灰度化后按图像 robust median/IQR normalization。
- 训练一个 patch verifier，参数量 `<=1M`，输出 `P(endpoint <=2px)`。
- 必须包含 score-only、raw-patch-only、feature-patch-only 消融。

### S：Structure Evidence

- 从 raw optical/SAR 生成结构通道：Sobel dx/dy、gradient magnitude、Laplacian、rank/census-like
  local order map。所有算子只用输入图像，不用 GT。
- 在 `33x33`、`65x65` patch 上计算结构相似特征，并训练结构 verifier，参数量 `<=1M`。
- 必须报告 hand-crafted structure scores 与 learned structure verifier。
- 结构通道不得使用 dataset-level 统计或 dev/OS424 标签调参。

### D：Descriptor Evidence

- 训练轻量 cross-modal local descriptor adapter；GDROS backbone/Transformer 保持冻结。
- adapter 输入可为 raw/structure/GDROS feature patch，输出 source/target descriptor，维度 `<=128`。
- 训练样本由 train split raw flow 生成：positive 为 endpoint `<=2px`，hard negatives 来自同 region、
  同 basin 和高 cosine 错误 candidate。
- loss 可用 supervised contrastive / InfoNCE / triplet / circle loss，必须在实验实现中固定一种主 loss。
- 推理只对 E-006A candidates 计算 descriptor score，不做 dense retrieval 或扩大候选空间。
- 必须报告 descriptor-only、descriptor+patch、descriptor+structure、all-evidence 融合。

## 4. 评价

主 dev track 固定为 `full-main global topK-32`，与 E-006A-SELECT-DIAG 对齐。

必须报告：

- candidate AUROC/AP/ECE；
- topK precision/recall for K `{16,32,64}`；
- topK/threshold/region-balanced affine AEPE、CMR@2/5、PLR、valid；
- selected inlier precision、active count 分布；
- 按 in-bounds/out-of-bounds、candidate source type、region count 分组；
- 资源：feature extraction time、selector/verifier time、peak memory。

主 solver 仍为 hard selected ordinary FP32 affine；one-step trimmed LS 只作诊断，不得作为主结果。

## 5. 判读

E-006A-SELECT-DIAG main D2 是冻结比较基线：

- baseline topK-32 precision：`2.259%`
- baseline affine AEPE：`63.516 px`
- baseline CMR@2：`0%`

判读类别：

- `STRONG_OBSERVATION_GAIN`：任一单路或融合证据达到 topK-32 precision `>=20%`、affine AEPE
  `<=5 px`、valid `>=95%`。
- `USEFUL_OBSERVATION_GAIN`：任一单路或融合证据达到 topK-32 precision `>=10%`，且 affine AEPE
  相对 baseline 降低 `>=30 px`，且 CMR@2 `>0%`。
- `WEAK_OBSERVATION_GAIN`：候选 AP 相对 baseline 提升 `>=0.03` 或 topK-32 precision 至少翻倍，
  但 affine AEPE 仍 `>33.516 px` 或 CMR@2 仍为 `0%`。
- `NO_USEFUL_OBSERVATION_GAIN`：以上均不满足。

如果多个方向有效，按 dev 主 track affine AEPE 排序，但不得自动启动下一实验。完成后写
`RESULT_CARD.md` 并等待方法任务和用户决策。
