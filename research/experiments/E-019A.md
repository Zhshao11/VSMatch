## 目的

> DINO-K256 中的高质量候选点，相比 outliers，是否具有局部到全局的几何共识特征？

本实验是上帝视角诊断。GT 只用于 label 和 oracle analysis；所有被评估的 features 必须在 label join
前物化，且必须是 no-GT inference 可计算的 proxy。

## 标签

在 feature materialization 后构造：

- endpoint error 和 labels <= `1/2/5 px`；
- per-source best positive；
- E-016A GT oracle inlier-set labels：all_hard K256 thr5、region-balanced B128 thr5；

## no-GT features

### Appearance/rank

- DINO rank、score、gap、per-source z-score、entropy；
- target nearest-score margin。

### Local geometry consensus

- source 8-neighbor / same-region neighbor displacement mean/median residual；
- displacement local density；
- similar displacement support count；
- source-neighborhood affine fit residual proxy。

### Regional geometry consensus

- 8x8 source region displacement mode support；
- adjacent region compatible displacement support；
- quadrant support / missing quadrant indicators。

### Global consensus proxy

- robust global displacement mode distance；
- Hough-style coarse affine bin vote/support，必须 deterministic low-cost，禁止 RANSAC/三点枚举；
- candidate support count under coarse affine bins；
- leave-region-out compatibility proxy，不使用 GT。

### Collision / coverage

- target duplicate count；
- target local density；
- many-source-to-one-target collision score；
- boundary/black-border flags；
- source region rarity、quadrant/region coverage gain；
- source xy condition contribution proxy。

### Fusion / diagnostic probe

- z-score/rank fusion；
- train-only logistic/linear probe over frozen features，dev-only evaluation；
- shallow tree feature importance，diagnostic only。

## 指标

每个 feature group / fusion 报告：

- endpoint@2 AP/AUROC；
- oracle-inlier-set AP/AUROC；
- P@topM、correct@topM，M=`32/64/128/256`；
- region-quota selection correct/precision/coverage；
- selected-set affine AEPE/CMR@1/2/5/PLR；
- positive vs negative quantiles；
- feature importance；
- failure buckets。

## 判读

- `GEOMETRY_CONSENSUS_SIGNAL_FOUND`：local/regional/global geometry proxy 在 dev endpoint@2 或
  oracle-inlier AP 上明显超过 DINO rank/score 和 E-017A score，并且 selected-set affine 明显改善
  E-017A/E-018A。
- `APPEARANCE_RANK_DOMINANT`：rank/score/margin 仍是最佳信号，geometry proxy 无明显增益。
- `COLLISION_OR_COVERAGE_DOMINANT`：target collision 或 coverage contribution 是主要可分因素。
- `NO_USABLE_PROXY_SIGNAL`：所有 no-GT proxy/fusion 仍无法形成可用高纯前缀或 selected-set affine。
- `IMPLEMENTATION_BLOCKED`：P0 或 reviewer 未通过。

若多项成立，主判读优先级：
`IMPLEMENTATION_BLOCKED > GEOMETRY_CONSENSUS_SIGNAL_FOUND > COLLISION_OR_COVERAGE_DOMINANT > APPEARANCE_RANK_DOMINANT > NO_USABLE_PROXY_SIGNAL`。
