# E-018A：DINO-K256 Affine-State-First Consensus

## 目的

E-018A 回答：

> 将 DINO-K256 候选集合先聚合为少数 affine state tokens，再用 affine residual 反向解释候选，是否能
> 替代 E-017A 的独立 candidate scoring，并形成可用的 no-GT 稀疏仿射配准？

这是结构替换实验，不是 threshold/PR/K512 rescue。

## 输入与隔离

- frozen DINOv2-L full4096 K256 candidates；
- DINO checkpoint SHA：
  `d5383ea8f4877b2472eb973e0fd72d557c7da5d3611bd527ceeb1d7162cbf428`；
- split 固定 `1607 train / 404 dev`；
- raw truth_flow 仅在 candidate score/id 物化并 hash 后用于训练标签和 dev 指标；
- 禁止 OS424/confirm/datum；
- 禁止 K512；
- 禁止修改或微调 DINO/GDROS/FeatureTransformer/E-015A/E-016A/E-017A artifacts。

## 模型

### Candidate/source encoding

每个 candidate 编码：

- source xy、target xy、displacement；
- DINO rank、score、gap、per-source z-score；
- source/target 8x8 region id、quadrant id、boundary flags；
- 若可安全读取 DINO embedding，可加入 source/target embedding、差值、乘积和 cosine；若不可用，记录 disabled reason。

每个 source 的 K256 candidates 先做 topK pooling / attention pooling 得到 source summary；8x8 source
regions 再聚合 region summary。禁止 candidate-candidate full self-attention 和 hidden `4096x4096`。

### Affine state tokens

- B=`8` affine tokens；
- tokens 从 source/region/global summaries 直接预测初始 affine `H_b` 与 confidence；
- 这是 primary path：禁止先用独立 candidate scorer 选 active set 再初始化 affine。

### Recurrent consensus

T=`4` rounds：

1. 对每个 candidate 和每个 affine token 计算 residual `q - H_b(p)`；
2. 用 residual + candidate features 预测 candidate-to-basin assignment、inlier weight 和 dustbin；
3. 每个 basin 执行 region-normalized FP32 weighted affine solve；
4. affine token 读取 residual histogram、coverage、inlier summaries 后更新 state；
5. 重复直到 T 轮完成。

### Final output

- 选择最高 confidence affine token；
- 每个 source 最多一个 target vote；
- final active set 由 chosen affine residual、learned inlier probability 和 region-balanced cap 决定；
- active 点数动态；
- final affine 使用 FP32 ordinary LS 或 weighted LS；
- 同时报告 direct affine token prediction 与 final active LS 两套指标。

## 训练

- affine token grid loss：每个 token 预测 affine flow，与 raw truth_flow 在固定 grid 上比较；
- winner/min loss：多 token 取最小 grid EPE，防止单 token 崩溃；
- diversity loss：鼓励不同 token 初期覆盖不同 hypothesis；
- state-conditioned inlier loss：candidate 相对 winner affine 和 GT endpoint 的 residual/inlier label；
- assignment/dustbin loss；
- final active affine grid loss；
- coverage/calibration loss，防止全拒绝/全接受。

必须证明 loss finite/nonzero，梯度到达 affine tokens、candidate-to-basin assignment、weighted solve /
residual feedback 和 final selection。toy/known-shift 必须可过拟合。

## G1 判读

dev no-GT inference。

主指标：

- direct affine token AEPE/CMR@1/2/5/PLR；
- final active LS AEPE/CMR@1/2/5/PLR；
- active count、correct@2、precision、coverage、condition；
- 对比 E-016A GT oracle、E-016A no-GT、E-017A K256。

判读：

- `STRONG_AFFINE_CONSENSUS`：AEPE `<=1.8 px`、CMR@2 `>=70%`、PLR `>=95%`；
- `WEAK_AFFINE_CONSENSUS`：AEPE `<=3.0 px`、CMR@2 `>=50%`、PLR `>=90%`；
- `STATE_GOOD_SELECTION_BAD`：direct affine token AEPE `<=3.0`，但 final active LS AEPE `>3.0`；
- `STATE_BAD`：direct affine token 与 final active LS 均 AEPE `>3.0`；
- `OUTLIER_CONTAMINATED`：active/coverage 足够但 precision 低且 final AEPE `>3.0`；
- `OVER_ABSTAIN`：active mean `<32` 或 coverage pass `<80%`；
- `IMPLEMENTATION_BLOCKED`：P0/G0/reviewer 未通过。

优先级：
`IMPLEMENTATION_BLOCKED > STRONG_AFFINE_CONSENSUS > WEAK_AFFINE_CONSENSUS > STATE_GOOD_SELECTION_BAD > OVER_ABSTAIN > OUTLIER_CONTAMINATED > STATE_BAD`。
