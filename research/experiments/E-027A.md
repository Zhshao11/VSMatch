# E-027A：Strong DINOv2 Pretraining Transfer for Opt-SAR Features

方法版本：`M001 v3.1 prototype`

状态：`USER_APPROVED / READY_FOR_ENGINEERING`

## 1. 目标

E-027A 目标是验证强预训练迁移是否能产生更好的 optical-SAR feature frontend。E-026A 已证明“只参考
DINOv2 结构、从零训练小网络”不够；E-027A 必须真实使用 DINOv2 预训练表示，让 SAR adapter 学会落到
optical DINO token descriptor 空间。

核心问题：

> 在同一个 E-025A fair matcher/NMS/affine evaluator 下，DINOv2 transfer + SAR adaptation 是否比
> frozen DINO、GDROS feature-only 和 E-026A scratch opt-SAR 更强？

本实验只证明 feature frontend gain；不宣称完整 sparse affine recurrent matcher 成功。

## 2. 已知对照

E-025A primary fair matcher：`topK256_nms2_quota4_mutual0`。

对照指标：

- `GDROS_FEATURE_FAIR`：AEPE `96.430`，recall@2 `0.729`，correct@2 `0.762`；
- `DINO_FOUNDATION_FAIR`：AEPE `79.246`，recall@2 `0.198`，correct@2 `0.163`；
- `E026A_SCRATCH_OPT_SAR`：AEPE `149.866`，recall@2 `0.0358`，correct@2 `0.0099`；
- 完整 GDROS system 只能作为 secondary reference，不参与 primary feature baseline。

## 3. 数据与边界

- train/dev split：train `1607`，dev `404`。
- 原始 optical/SAR 固定 `512x512`。
- `truth_flow` 只用于 train loss、label 和 metrics。
- `datum` 仅做 archive 完整性/SHA，不作为标签。
- OS424/confirm 禁止参与。
- GDROS baseline、DINOv2 checkpoint、历史 feature/cache/run 目录只读。
- 若复制 DINOv2 权重到 E-027A checkpoint，只能修改该实验副本；原始 checkpoint 必须 SHA 绑定且只读。

## 4. 模型路线

### Primary track：`FROZEN_DINO_OPTICAL__SAR_ADAPTER`

```text
optical 512x512
  -> frozen DINOv2 optical encoder
  -> optical teacher/reference tokens

SAR 512x512
  -> log/structure/speckle-robust SAR stem
  -> trainable SAR-to-DINO adapter/projection
  -> SAR descriptors in optical DINO space

optical teacher tokens + SAR adapted tokens
  -> E-025A primary fair matcher
  -> same affine evaluator
```

绑定：

- optical DINO teacher 不训练；
- SAR stem/adapter/projection 训练；
- positive pair 由 train `truth_flow` 将 optical token 映射到 SAR token；
- hard negatives 必须覆盖 same-pair non-match、nearby hard negatives 和 cross-pair negatives。

### Secondary track：`DINO_COPIED_ADAPTER_OR_LORA`

允许将 DINOv2 权重复制到 E-027A checkpoint，并训练：

- SAR adapter；
- modality adapters；
- descriptor projection；
- LoRA 或少量指定 transformer adapter。

禁止修改原始 DINOv2 checkpoint。若资源不足或工程不可行，记录 `documented_unavailable`，但 primary track
不能退化为 scratch-only network。

## 5. Loss

必须包含：

- DINO teacher alignment loss：SAR descriptor 对齐 GT 对应 optical DINO token；
- optical→SAR / SAR→optical sampled-softmax 或 InfoNCE；
- hard-negative contrastive/listwise loss；
- cycle 或 mutual consistency；
- soft affine/grid loss；
- SAR augmentation consistency：speckle/noise/intensity/log-scale perturbation 后保持匹配；
- 若 optical side 存在 trainable adapter/LoRA，必须有 optical teacher consistency，避免丢失 DINO prior。

允许：

- multi-layer DINO token fusion；
- LoRA rank sweep；
- stride-8 secondary diagnostic；
- train-only GDROS teacher auxiliary。

禁止把 GDROS teacher 或 DINO teacher 输出称为 GT；必须单独报告各 loss。

## 6. 评价

正式 dev 比较：

```text
feature extractor / transfer model
-> materialize descriptors before truth_flow join
-> E-025A primary fair matcher topK256_nms2_quota4_mutual0
-> same affine evaluator
-> compare with DINO_FOUNDATION_FAIR, GDROS_FEATURE_FAIR, E026A_SCRATCH_OPT_SAR
```

必须报告：

- endpoint recall@1/2/5；
- GT endpoint rank / topK recall；
- selected count；
- selected correct@2 mean/P50；
- fair affine AEPE；
- CMR@2 / CMR@5；
- PLR；
- target collision；
- region/quadrant coverage；
- train/dev gap；
- resource p50/p95/max 和 peak memory；
- frozen/trainable parameter counts。

## 7. Gate

### P0：implementation and isolation

必须 PASS：

- DINOv2 pretrained weights actually loaded and used in primary transfer track；
- primary track is not scratch-only；
- original DINOv2/GDROS/baseline checkpoint and cache readonly；
- SAR adapter/stem/projection exists, is called, and is trainable；
- copied checkpoint / teacher / initialization SHA recorded；
- no baseline writes；
- no OS424/confirm/datum；
- train/dev split isolation；
- feature materialized before truth_flow join；
- primary matcher config 与 E-025A 一致；
- no dev matcher/threshold selection。

P0 fail：`DINO_TRANSFER_IMPLEMENTATION_BLOCKED`。

### G0：transfer training sanity

必须 PASS：

- train loss finite 且主要 loss 非零；
- teacher alignment loss 下降或 train retrieval 明确改善；
- gradients 到达 SAR adapter/projection 以及声明训练的 LoRA/adapters；
- declared frozen modules 保持 frozen；
- strict checkpoint load；
- train no-GT hard matcher inference finite；
- train feature utility 超过 E-026A scratch 或初始化/随机 reference；
- reviewer 对 transfer/隔离链路 approve。

G0 fail：`DINO_TRANSFER_TRAINING_BLOCKED`。

### G1：dev feature comparison

判读：

- `NO_DINO_TRANSFER_GAIN`：transfer feature 未超过 DINO foundation 或 E-026A scratch 的核心指标；
- `DINO_TRANSFER_GAIN_FOUND`：相对 `DINO_FOUNDATION_FAIR`，AEPE 改善 `>=10%` 且 recall/correct 不低于 DINO；
  或 recall/correct 改善 `>=50%` 且 AEPE 不比 DINO 差超过 `10%`；
- `GDROS_RECALL_BRIDGE_FOUND`：recall@2 或 correct@2 达到 `GDROS_FEATURE_FAIR` 的 `>=50%`，且 AEPE 优于 GDROS；
- `TRANSFER_FRONTEND_STRONG_GAIN`：AEPE 相对 DINO 改善 `>=25%`，且 recall/correct 同时优于 DINO；
- `READY_FOR_SPARSE_FEEDBACK_FRONTEND`：feature 指标达到可作为下一版 R0/coarse/local observation 输入的阈值。
