# E-025A：Feature Frontend Fair Matching Benchmark

方法版本：`M001 v2.9 diagnostic`

状态：`USER_APPROVED / READY_FOR_ENGINEERING`

## 1. 目标

E-025A 专门比较 optical-SAR 特征前端，而不是比较完整 detector-free matcher 系统。GDROS 是 detector-free /
dense matching baseline，其完整性能来自 feature + correlation/transformer/GRU/flow update，不能用统一 NMS
代表完整系统。但可以用统一 matcher 公平评价它的 feature-only separability。

核心问题：

> 在同一个 fair matcher/NMS/affine evaluator 下，有没有 frozen prior、先验监督训练或 teacher distillation
> 得到的新 feature 比 GDROS feature-only baseline 更好？

## 2. 数据与边界

- train/dev split：train `1607`，dev `404`。
- 原始 `512x512` optical/SAR。
- `truth_flow` 只用于 train loss、label 和 metric。
- OS424/confirm/datum 禁止参与。
- GDROS/DINO/baseline checkpoint 只读。
- 完整 GDROS system 只作为 secondary reference，不作为 primary feature baseline。

## 3. Feature tracks

必须实现/尝试：

### A. Frozen / prior tracks

1. `GDROS_FEATURE_FAIR`
   - 冻结 GDROS feature；
   - 用统一 fair matcher 评价；
   - primary baseline。

2. `DINO_FOUNDATION_FAIR`
   - 冻结 DINO/foundation feature；
   - 若本地 checkpoint 不可用，记录 unavailable；
   - 不微调。

3. `STRUCTURE_PRIOR_FAIR`
   - gradient/census/local energy/phase/edge/bar 等结构先验；
   - 作为无训练 feature baseline。

### B. Trainable descriptor tracks

4. `SUPERVISED_XMODAL_DESCRIPTOR`
   - dual-stream 或 shared+modality adapter；
   - train truth_flow 构造 token-level positives/hard negatives；
   - 训练时使用 differentiable fair matcher；
   - 推理统一 hard fair matcher。

5. `GDROS_TEACHER_DISTILLED_DESCRIPTOR` 或 `HYBRID_GT_TEACHER_DESCRIPTOR`
   - teacher 为 frozen GDROS train-only predicted flow/soft correspondences；
   - teacher outputs 必须在 truth_flow join 前物化并 hash；
   - 可混合 GT loss，但 dev 不得用 teacher/GT 调参；
   - 不修改 teacher checkpoint。

### C. Optional paper/checkpoint tracks

可尝试 PromptMID/SOMA/S²M²-SAR/TAR/RemoteCLIP/其他 SAR-optical descriptor。若官方 code/checkpoint 不可用，
只记录 unavailable，不伪称复现。

## 4. Unified fair matcher

所有 feature 必须经过同一 matcher：

- descriptor normalize；
- scale primary `1/16`；secondary `1/8` chunked if feasible；
- similarity：cosine 或统一 dual-softmax；
- budgets：topK `64/128/256/512`；
- NMS radius sweep：`1/2/4` tokens；
- region quota sweep：`1/2/4/8`；
- mutual/cycle consistency fixed option；
- deterministic affine LS/evaluator；
- primary matcher setting 必须 pre-registered 或 train-only selected，禁止 dev 后验挑最优设置。

允许为训练使用 soft matcher：

- dual-softmax / Sinkhorn-lite / soft topK / entmax / sparsemax；
- differentiable weighted affine/grid loss；
- 但推理和正式比较必须回到 unified hard matcher。

## 5. Loss

Trainable descriptor loss 可包含：

- source-to-target token CE；
- target-to-source token CE；
- InfoNCE / supervised contrastive；
- hard negative focal；
- cycle consistency；
- peak sharpness / margin；
- region coverage/diversity；
- differentiable affine/grid loss；
- teacher flow/correspondence distillation loss（train-only）。

不得把学习 frozen GDROS teacher 输出称为 truth GT；需要区分 `GT-supervised` 与 `teacher-distilled`。

## 6. Metrics

### Feature retrieval

- endpoint recall@1/2/5 px；
- GT endpoint rank / topK recall；
- mutual match precision/recall；
- local/correlation peak margin；
- target collision rate；
- region/quadrant coverage。

### Affine utility

- selected match count；
- correct@2 mean/P50；
- fair affine AEPE；
- CMR@2 / CMR@5；
- PLR；
- R0 selected/oracle-best AEPE；
- R1 window coverage when used as coarse init。

### References

- `GDROS_FEATURE_FAIR` 是 primary baseline；
- complete GDROS system 是 secondary reference；
- DINO/full system results from E-015A~E-024A are readonly context only。

## 7. Gate

### P0：fairness and implementation

必须 PASS：

- all features through same fair matcher/evaluator；
- complete detector-free system reference clearly separated；
- GDROS/DINO/baseline readonly；
- no OS424/confirm/datum；
- feature materialized before truth_flow label/metric join；
- teacher outputs materialized before GT join；
- train/dev split isolation；
- no dev oracle/matcher setting selection；
- source/checkpoint SHA for every feature。

P0 fail：`FEATURE_BENCHMARK_IMPLEMENTATION_BLOCKED`。

### G0：train/source sanity

必须 PASS：

- `GDROS_FEATURE_FAIR` completed；
- at least two non-GDROS frozen/prior features completed or explicitly unavailable；
- supervised descriptor training completed：loss finite/decreases, gradients nonzero, strict load；
- teacher/hybrid descriptor completed if teacher source available, else source-unavailable recorded；
- train no-GT hard matcher finite；
- no baseline writes。

G0 fail：`FEATURE_TRAINING_OR_SOURCE_BLOCKED`。

### G1：dev fair comparison

Primary comparison：best non-GDROS feature vs `GDROS_FEATURE_FAIR` under same primary fair matcher.

判读：

- `NO_FEATURE_FRONTEND_GAIN`
- `FROZEN_PRIOR_FEATURE_GAIN_FOUND`
- `SUPERVISED_DESCRIPTOR_GAIN_FOUND`
- `TEACHER_DISTILLED_DESCRIPTOR_GAIN_FOUND`
- `FEATURE_FRONTEND_STRONG_GAIN`
- `FEATURE_APPROACHES_SYSTEM_BASELINE`

Thresholds：

- weak gain：fair affine AEPE 或 endpoint recall 比 `GDROS_FEATURE_FAIR` 改善 `>=10%`；
- strong gain：fair affine AEPE 改善 `>=25%`，且 selected correct@2 / recall 同时改善；
- approaches system baseline：需报告相对 complete GDROS system，但只能 secondary。

## 8. 审阅

1. feature/fairness reviewer：

2. training/protocol reviewer：

   - metrics aggregation。

blocking finding：`IMPLEMENTATION_BLOCKED`。
