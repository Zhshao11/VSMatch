# E-021A：Probabilistic Set Selection for Inlier Enrichment

## 目的

E-021A 回答：

> 不要求网络逐候选拟合 GT，只学习一个选择分布，能否让正确点比错误点更高概率进入 selected set，
> 并让 selected set 的几何分布足以改善 affine？

这是对 E-020B 的方法转向：从 hard candidate classification / AP 排序，转为 set-level inlier
enrichment 和 affine utility。

## 输入与隔离

- frozen DINOv2-L full4096 K256 candidates；
- DINO checkpoint SHA：
  `d5383ea8f4877b2472eb973e0fd72d557c7da5d3611bd527ceeb1d7162cbf428`；
- official training split：train `1607` / dev `404`；
- 原始 optical/SAR `512x512` 图像；
- raw truth_flow 仅用于 train reward/loss、dev metrics 和 oracle diagnostics；
- 禁止 OS424/confirm/datum；
- 禁止修改 DINO/GDROS checkpoint、baseline source、E-015A~E-020B artifacts。

## 方法

### Selection distribution

- 对每个 source 的 K256 candidates 输出 probability；
- 每 source 最多一个 target，可 dustbin；
- 支持 stochastic sampling、Gumbel-topK、straight-through topK 或 differentiable soft topK；
- 训练时记录 selection entropy、expected selected count、source/region coverage；
- 推理时使用预注册 deterministic expected-topK / train-calibrated budget，不用 dev 调参。

### Set-level objective

训练目标不是 candidate AP，而是：

- soft inlier reward：`<=2px` hard reward，`<=5/8px` partial reward 或 soft endpoint score；
- enrichment objective：提高 `P(inlier | selected)`；
- weighted affine/grid utility：对 selected/soft-selected set 拟合 affine，用 train truth_flow grid loss 或
  可微 surrogate 训练；
- outlier contamination penalty：惩罚高权重 outlier；
- coverage/diversity/budget：保持区域/象限覆盖和合理点数。

## G0：train-full enrichment sanity

G0 在 1607 train pairs 上训练并 no-GT train inference。小样本只 sanity。

至少一个预注册 track 同时满足：

- enrichment ratio@2 >= `3x` candidate-pool base rate；
- enrichment ratio@2 >= `1.5x` E-020B top256 precision；
- correct@2 mean >= `8`；
- P50 correct@2 >= `4`；
- precision@2 >= `3%`；
- selected-set AEPE <= `25 px` 或相对 E-020B top256 AEPE `35.686` 改善 >= `25%`；
- source regions mean >= `32` 或 quadrant coverage mean >= `3.5`。

若 G0 不过，状态 `SET_ENRICHMENT_TRAIN_FAIL`，不跑 dev404。

## G1：dev404 no-GT enrichment

G0 PASS 后运行 dev404。固定 tracks：

- expected topM：`32/64/128/256`；
- region quota：`1/2/4`；
- stochastic samples with fixed train seed；
- train-calibrated budget/threshold；
- dynamic expected budget。

报告：

- candidate pool base rate；
- selected precision@2/5/8；
- enrichment ratio；
- correct count mean/P10/P50/P90；
- selected count、coverage、condition；
- selected-set AEPE/CMR@1/2/5/PLR；
- comparison to DINO score、E-020B score、random、region quota。

## 判读

- `IMPLEMENTATION_BLOCKED`：P0 或 reviewer blocking。
- `IMPLEMENTATION_BLOCKED_OR_MODEL_TOO_WEAK`：selection distribution / affine utility / coverage 主通道不成立。
- `SET_ENRICHMENT_TRAIN_FAIL`：train-full 都无法富集。
- `TRAIN_ENRICHMENT_DEV_FAIL`：train-full 富集，dev404 不泛化。
- `ENRICHMENT_FOUND_AFFINE_FAIL`：dev 内点富集明显，但 affine 仍差。
- `USEFUL_SET_SELECTION_FOUND`：dev selected-set affine 明显改善 E-020B/E-018A。
- `STRONG_SET_SELECTION_FOUND`：dev 接近进入完整 sparse affine feedback。
